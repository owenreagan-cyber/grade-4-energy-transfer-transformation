# CH1 NOTE-FORMAT COMPARISON — CLASSROOM TIME SIMULATION

> Part I. Deterministic, per-session timing. Assumptions (documented, conservative for a 4th-grade room of 20):
> - 1 insert/page is completed per note session; the week has 3 note sessions (Mon/Wed/Thu).
> - Fill-in blank = 20 s each · short drawing = 2 min · flap fold+lift = 45 s · one trim+glue = 60 s · teacher model = 2 min.
> - Shared-scissor/glue friction = 60 s/session for INB (a classroom of 20 sharing supplies).

## INB (per insert session)

| Activity | Minutes |
|---|---|
| Distribution (inserts + scissors/glue) | 1.0 |
| Trim dashed line (1 insert) | 0.5 |
| Glue top edge | 0.5 |
| Lost-scissors/glue friction | 1.0 |
| Teacher model (foldable/writing) | 2.0 |
| Fill-in blanks (≈3) | 1.0 |
| Drawing (before/after or example) | 2.0 |
| Flap fold + lift + read reveal | 0.75 |
| Cleanup (return supplies, close notebook) | 1.0 |
| **Total per session** | **~9.75 min** |

## Guided Notes (per page session)

| Activity | Minutes |
|---|---|
| Distribution (one sheet) | 0.5 |
| Teacher model | 2.0 |
| Fill-in blanks (3–4) | 1.0 |
| Drawing | 2.0 |
| Explanation / reasoning (synthesis) | 2.0 |
| Collection / storage in folder | 0.5 |
| **Total per session** | **~8.0 min** |

## 30-minute lesson (tight)

| | INB | Guided Notes |
|---|---|---|
| Instructional minutes | ~20 | ~22 |
| Assembly minutes | ~2.0 | 0 |
| Writing/drawing minutes | ~3.75 | ~5.0 |
| Transition minutes | ~2.5 | ~1.0 |
| **Feasibility** | WARN — assembly + transitions consume ~4.5 min; note session must be trimmed | PASS — fits comfortably |

## 45-minute lesson

| | INB | Guided Notes |
|---|---|---|
| Instructional minutes | ~35 | ~37 |
| Assembly minutes | ~2.0 | 0 |
| Writing/drawing minutes | ~3.75 | ~5.0 |
| Transition minutes | ~2.5 | ~1.0 |
| **Feasibility** | PASS | PASS |

## Unit-level time note
- INB assembly cost ≈ **+2.0 min/session × 3 sessions/week ≈ +6 min/week ≈ +54 min/9 weeks** (vs Guided Notes) — nearly a full class period per week reclaimed for instruction/labs.
- The 30-minute-period simulation is the binding constraint: INB is feasible but tight; Guided Notes are clearly safe.
