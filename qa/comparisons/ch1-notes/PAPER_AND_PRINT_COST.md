# CH1 NOTE-FORMAT COMPARISON — PAPER AND PRINT COST

> Part J. **20 students.** Sheet consumption only (no dollar amounts — no price data assumed). Both formats are single-sided for Chapter 1 (INB inserts must be single-sided to trim/glue; Guided Notes use 3 pages but are duplex-optional).

## INB
- Printed sheets/student: **3** (one insert per sheet, single-sided — required, so the back can be trimmed/glued without destroying content).
- Total sheets for 20: **60**.
- Double-sided feasibility: **NO** (cut-and-paste inserts must be one-sided).
- Cut waste: each insert is trimmed from a Letter sheet → ~15–20% of each sheet becomes trim scrap (7×9 vs 8.5×11). Effective waste ≈ 9–12 sheets-equivalent across 20 students.

## Guided Notes
- Printed sheets/student: **3** (Pages 1–3).
- Total sheets for 20: **60**.
- Duplex feasibility: **YES** (Pages 1–3 can print duplex → 2 sheets/student, 40 sheets for 20, if the teacher prefers two-sided; no cutting/gluing means both faces are usable).
- Cut waste: **none**.

## Comparison
| | INB | Guided Notes |
|---|---|---|
| Sheets/student (single-sided) | 3 | 3 |
| Sheets for 20 (single-sided) | 60 | 60 |
| Duplex possible | No | Yes (→ 40 sheets for 20) |
| Cut/trim waste | ~15–20% scrap | 0% |

**Result:** at face value both use 3 sheets/student; Guided Notes can halve consumption with duplex printing, while INB cannot and additionally produces trim scrap. Paper is a mild advantage for Guided Notes, not a decisive factor at this unit's print volume.
