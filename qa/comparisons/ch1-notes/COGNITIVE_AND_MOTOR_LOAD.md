# CH1 NOTE-FORMAT COMPARISON — COGNITIVE AND MOTOR LOAD

> Part H. Separates **content cognitive load** (identical by design) from **format/motor load** (the comparison variable). Counts from `tools/qa_ch1_notes.py`.

## Content cognitive load (held equal)

| Measure | INB | Guided Notes |
|---|---|---|
| Total student-facing words | 548 (incl. repeated assembly labels ×3) | 334 |
| Core definition fill-ins | 3 | 3 |
| Total fill-in blanks | 8 | 10 |
| Written responses (free) | 6 (scavenger record) + 1 draw + 3 flap reads | 4 (evidence table) + 1 synthesis + 1 draw |
| Drawing tasks | 2 (before/after + stored-energy) | 2 (before/after + stored-energy) |
| Model to recite/trace | ENERGY→CHANGE→EVIDENCE (×2) | ENERGY→CHANGE→EVIDENCE (×2) |

The **concepts, definitions, examples, and models are equivalent** — content cognitive load is effectively equal.

## Format / motor load (the difference)

| Action | INB | Guided Notes |
|---|---|---|
| Cutting (trim dashed line) | 3 (one per insert) | 0 |
| Gluing (top edge) | 3 | 0 |
| Folding / flap manipulation | 3 lift-flaps (+1 flat option) | 0 |
| Scissors/glue retrieval & return | 3 sessions | 0 |
| Physical transitions (get/put supplies) | ~6 | ~2 |
| Total discrete motor actions | ~12–15 | ~2–3 |

## Interpretation
- INB adds ~10–12 motor/assembly actions across the week that Guided Notes do not have. This is the primary source of the INB's classroom-time and accessibility cost, and it does **not** buy additional science content — the foldable reveals the same "stored energy can cause a change later" fact the Guided Notes print on the page.
- Guided Notes put nearly all student effort into **thinking and writing**, not assembly.
