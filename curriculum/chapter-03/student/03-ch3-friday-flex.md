## PRACTICE — The Fast & The Curious (tabletop data challenge)
| Field | Value |
|---|---|
| Time | 15–20 min |
| Materials | ramp data cards + clue strips (no physical locks) |
| Teacher prep | low — print/cut |
| Student independence | guided |
| Printable | yes |
| Reusable | yes |
| Concepts reinforced | data reading · same-object reasoning · measured vs inferred |

**Activity:** Students work through 5 steps to "unlock" a 5-digit code (a word/numbers written on paper — no locks):
1. **Interpret** a small ramp table (1/2/3 books → cup displacement).
2. **Identify** the faster/slower trial using the SAME object.
3. **Match** evidence to the claim (faster → greater energy of motion).
4. **Correct** a false conclusion ("the heavier ball must be the reason").
5. **Unlock** the code by combining one digit/letter from each step.

**Activity:** Students find the errors in each sample graph:

- missing unit (cm)
- bad title ("Speed vs. Energy")
- unsupported conclusion ("we measured the energy")
