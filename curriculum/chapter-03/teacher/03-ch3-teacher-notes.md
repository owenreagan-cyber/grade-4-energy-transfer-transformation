# Chapter 3 Teacher Notes

> Background, key distinctions, and pitfalls for teaching "Energy and Speed Are Related."

## Source framing (verbatim intent)
- **speed** = a measurement of the distance an object travels over an amount of time (Reader p.13; Glossary).
- **energy of motion** = the energy an object possesses while it is moving (Reader p.9; Glossary).
- "Greater Speed Is Related to Greater Energy" — "Objects with Greater Energy Cause Greater Changes" (Reader p.14).
- Steeper ramp → faster ball → knocks the bucket farther/over (Reader p.15).
- Higher bounce + louder sound = greater change = greater energy (Reader p.16).

## The recurring model (Chapter 3 slice)
```
SAME OBJECT → FASTER MOTION → GREATER ENERGY OF MOTION → GREATER OBSERVED CHANGE
```
The SAME OBJECT condition is essential (TG "Know the Science": "be sure when discussing speed and motion energy that you make comparisons only between the same object moving at different speeds"). Do NOT vary mass/object type.

## Measured vs. inferred (teach explicitly — the heart of this chapter)
- **MEASURED:** ramp height (books) · cup displacement (cm) · drop height (cm) · crater width (cm).
- **INFERRED:** relative speed · the speed↔energy relationship · any "energy" quantity.
- TG "Know the Standards": students at this level are **not** required to quantitatively measure speed or energy — they use observable changes to compare.
- Never label a graph "Speed vs. Energy." Use "Ramp Height vs. Average Cup Displacement" (both axes measured).

## Fair test (locked)
- Ramp It Up! 2.0 — CHANGE ramp height; KEEP the same ball, target cup, surface, release point, measurement method; MEASURE cup displacement.
- Drop It — CHANGE drop height; KEEP the same ball, sand tray, surface; MEASURE crater width.

## Speed vs. distance (avoid conflation)
- speed = distance **over an amount of time** (a rate).
- distance = how far something moved.
- Students should not claim they measured speed when they measured displacement.

## Do NOT
- Teach "ramp height = speed" as identical variables.
- Claim students directly measured energy or speed.
- Introduce kinetic/potential/mechanical energy, velocity, acceleration, momentum, force, joule, gravitational potential energy.
- Vary mass or object type in any comparison.

## Vocabulary classification note
- **speed** and **energy of motion** are Core Vocabulary (Reader pp. 13, 9).
- **motion** (p.7) is revisited Core Vocabulary.
- **evidence**, **position**, **variable** are Language of Instruction (not Core Vocabulary) — used heavily for the fair test and CER.

## Do NOT
- Reuse the old draft Drop It knee/waist/shoulder design (inconsistent across student heights) — use fixed cm heights.
- Reuse millimeter-depth precision (false precision) — crater depth stays qualitative.
