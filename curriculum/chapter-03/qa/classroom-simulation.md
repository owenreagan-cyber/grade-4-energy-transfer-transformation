## Investigation bottlenecks found
1. **Ramp setup (Tue)** — ramps/books/cups distribution. → Mitigated: pre-assembled ramp kits per group; tape start markers.
2. **Trial reset (Tue)** — cup tips, ball misses. → Mitigated: low cup, light backstop, "release don't push."
3. **Averaging (Tue/Wed)** — 9 numbers to average. → Mitigated: averages moved to Wednesday; calculator allowed.
4. **Graphing (Wed)** — axes, labels, scaling. → Mitigated: pre-ruled grid on the ramp page + graph-setup slide #18.
5. **Measured-vs-inferred confusion** — students claim "we measured speed/energy." → Mitigated: repeated REVEAL cues (slides #20/#23) + Insert 3 flap.
6. **Drop It sand spills (Thu)** — → Mitigated: trays on newspaper; "smooth, don't throw"; fixed-height guide prevents over-reaching.
7. **Drop It crater measurement** — edges collapse. → Mitigated: measure widest clear edge; re-smooth between trials.
8. **Fast finishers** — → Mitigated: optional 90 cm height; Friday EXTEND real-world analysis.

## Fixes applied
- Fixed drop heights (30/60/90 cm) replace body-relative heights → fair across student sizes (documented ADAPTED).
- Qualitative crater depth (no mm) → no false precision.
- Graph grid pre-ruled → Grade 4-usable.
