## PRACTICE — Motion Evidence Sort
| Field | Value |
|---|---|
| Time | 15 min |
| Materials | sort cards (scenarios) + 3 header cards |
| Teacher prep | low — print/cut |
| Student independence | guided |
| Printable | yes |
| Reusable | yes |
| Concepts reinforced | moving object · change caused · evidence |

**Activity:** Students sort cards into three columns:
1. **moving object** (e.g., "a rolling marble")
2. **change caused** (e.g., "the target marble moved")
3. **evidence** (e.g., "I saw the target move from here to there")

## PRACTICE — Observation vs Inference
| Field | Value |
|---|---|
| Time | 10 min |
| Materials | sentence strips |
| Teacher prep | low |
| Student independence | guided |
| Printable | yes |
| Reusable | yes |
| Concepts reinforced | observation vs inference |

**Activity:** Students sort statements into "observation" or "inference":
- Observation: "The cup moved 12 cm."
- Inference: "The marble had energy."
- Observation: "The target marble changed position."
- Inference: "The moving marble caused the change."

## EXTEND — Motion Mystery Files
| Field | Value |
|---|---|
| Time | 15 min |
| Materials | clue strips |
| Teacher prep | low |
| Student independence | guided |
| Printable | yes |
| Reusable | yes |
| Concepts reinforced | moving object → change → evidence |

**Activity:** Give a short scenario ("A rolling ball bumped a block and the block slid forward."). Students identify the **moving object**, the **change**, and the **evidence**.

**Optional challenge:** design a safe tabletop setup where one moving object causes another object to change (no launching, no ramps).
