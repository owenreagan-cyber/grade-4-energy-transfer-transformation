## PRACTICE — Motion Evidence Sort
| Field | Value |
|---|---|
| Time | 15 min |
| Materials | this page |
| Teacher prep | low — print/cut |
| Student independence | guided |
| Printable | this page |
| Reusable | yes |
| Concepts reinforced | moving object · change caused · evidence |

The printable page is `production/worksheets/02-ch2-friday-flex.docx`.

Cut out the 9 cards. Match each object with the change it causes and the evidence that shows it has energy. The cards are shuffled. Matching object, change, and evidence are not in the same row.

OBJECT cards: Hammer · Pendulum · Wind

CHANGE cards: The blades spin · The nail goes into the wood · The clock gears turn

EVIDENCE cards: I saw the gears move · I saw the blades start to turn · I saw the nail move into the wood

Sort mat columns: Object | Change | Evidence

The matched sets are on the teacher key only.

## EXTEND — Motion Mystery Files
| Field | Value |
|---|---|
| Time | 15 min |
| Materials | this page |
| Teacher prep | low |
| Student independence | guided |
| Printable | this page |
| Reusable | yes |
| Concepts reinforced | moving object → change → evidence |

**Activity:** For each story, name the moving object, the change, and the evidence.
1. A rolling cart pushes a box. The box slides across the floor.
2. A swinging door bumps a ball. The ball rolls away.
3. A toy car knocks over a stack of blocks. The blocks fall.

**Optional challenge:** design a safe tabletop setup where one moving object causes another object to change (no launching, no ramps).
