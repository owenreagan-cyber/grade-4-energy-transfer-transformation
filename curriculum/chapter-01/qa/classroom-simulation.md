## Bottlenecks found
1. **Writing overload (Tue):** 6-column evidence model × 3 examples. → Mitigated: limited to 3 (matches AP 1.1), landscape page, ruled lines not blank boxes.
2. **Prep bottleneck (Wed):** flashlight + cup/balloon/salt + optional candle. → Mitigated: candle optional; salt demo prep flagged in supply guide.
3. **Teacher talk (Mon):** discussion can over-run. → Mitigated: timed transitions, prediction-before-reveal structure.
4. **Dead time (Tue):** fast finishers. → Mitigated: "write a question" + Friday EXTEND.
5. **30-min split:** Tuesday investigation only fits at 45; documented split path (2 examples + Friday RECOVER).

## Fixes applied
- Detectives limited to 3 examples; landscape 6-column table with ≥1.1" rows.
- Battery sequence staged explicitly (observe→predict→device→change→stored energy).
- Candle marked optional; salt demo no-eating.
- 30-min splits documented in daily lessons.

## Result: **PASS** (with documented 30-min splits for Tuesday)
