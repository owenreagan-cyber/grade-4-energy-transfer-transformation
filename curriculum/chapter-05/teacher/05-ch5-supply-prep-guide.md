# Chapter 5 Supply / Prep Guide

> Per group of 4. Class totals = GROUP_COUNT × amount (see `docs/planning/CURRENT_DECISIONS.md` for the locked GROUP_COUNT; do NOT invent total quantities here). Reusable vs consumable marked.

## CRASH LAB (per group)
- toy car(s) — same type/size for Part A (speed) — **reusable**
- additional cars or addable weights (e.g., 2–3 identical cars taped, or washers/clay taped on top) for Part B (mass/weight) — **reusable**
- ramp: cardboard or wood plank (~2 ft) — **reusable**
- books/blocks for 3 ramp heights (1 / 2 / 3 books) — **reusable**
- target: plastic cup or small block — **reusable**
- meter stick or ruler (cm) — **reusable**
- tape to mark the release point and target start line — **consumable**
- student worksheet `05-ch5-crash-lab-student.docx` (1/student) — **consumable**

## Whole-class / teacher
- Newton's cradle (1, teacher demo only) — **reusable** (optional; video OK)
- index cards for vocabulary deck (2 per student) — **consumable**
- chart paper / board markers — **reusable**
- student worksheets (crash lab + practice + quiz) — **consumable**
- Interactive Science Notebook inserts (1 set per student) — **consumable**

## Prep
1. Pre-build ramps (plank on a book stack); mark release points at 1/2/3 books for Part A and a single fixed height for Part B.
2. Confirm all Part A cars are the SAME type/size (no mixing brands in the speed test).
3. Prepare Part B mass sets (1 car / 2 cars taped / 3 cars taped — or cars + taped washers) so students add mass WITHOUT changing ramp or car type.
4. Pre-test that the target (cup/block) slides — not tips — for clean displacement measurement.
5. Pre-print worksheets and notebook inserts; pre-cut the notebook flap if time allows.
6. Set up the Newton's cradle for the Monday demo (teacher only).

## Cleanup
- Return cars, ramps, books/blocks, targets, meter sticks to labeled bins.
- Remove tape from desks/floor; reset crash lanes.
- Newton's cradle stored out of student reach.

## Storage
- Cars separated by type (Part A "same type" sets vs Part B "mass" sets); ramps and books stacked; targets binned.

## Failure modes & fixes
| Failure | Likely cause | Fix |
|---|---|---|
| Target tips instead of sliding | target too tall / hit off-center | use a low cup/block; aim down the lane center |
| Displacement hard to measure | no start line / target moved off-lane | tape a start line; keep target in the lane |
| Part A cars not identical | mixed brands/sizes | pre-check: same car type for the speed test |
| Part B mass not the only change | cars of different type | use identical cars taped together (or taped washers) |
| Newton's cradle mishandled | students swing it | teacher demo only; keep out of reach |

## Safety
- Clear crash lane (no one in the path); cars ROLL, never thrown; fixed release points.
- No projectiles toward people; no open flames; no heat measurement.
- Newton's cradle = teacher demonstration only.
