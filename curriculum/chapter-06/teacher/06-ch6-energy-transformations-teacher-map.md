# Essential Understandings
- Energy can change from one form to another (**transformation**).
- Energy can move from object to object or place to place (**transfer**).
- A single system can involve **BOTH** transfer and transformation.
- Engineered devices use energy transformations to solve problems.
- Engineers **design → build → test → refine**.
- Success is judged against **criteria** (desired features) under **constraints** (limitations).
- Test results — including failures — are useful evidence for refining a design.

# Student-Friendly Targets ("I can…")
- I can tell the difference between energy **transfer** and energy **transformation**.
- I can trace a device's **input → change in form → output/change**.
- I can decide whether a system shows **transfer, transformation, or BOTH**.
- I can name the **problem, criteria, and constraints** for a design.
- I can draw and label a **blueprint** and predict my device's **energy pathway**.
- I can **test** my device, **record evidence**, and **refine** it based on results.
- I can **explain** my energy pathway using evidence (not "prove").

# Core Model
```
INPUT → CHANGE IN FORM (TRANSFORMATION) → OUTPUT / OBSERVABLE CHANGE
```
Plus the three-way classification:
```
TRANSFER = energy moves
TRANSFORMATION = energy changes form
BOTH = energy moves AND changes form (may both occur)
```

# Transfer / Transformation / BOTH distinction
- **Transfer:** warm water → cooler spoon (energy moves; same form — heat).
- **Transformation:** battery in a flashlight → light (energy changes form).
- **BOTH:** falling dominoes (motion transfers AND a little motion → sound) or a toy-car collision (motion transfers to target AND becomes sound).

# Capstone Problem (ADAPTED)
**Tabletop Alert / Signal Device.** Design a non-electrical tabletop device that produces a clear signal when a model door/gate/trigger moves. The device must demonstrate at least one energy transformation.

# Criteria (measurable)
- responds to the trigger (model door/gate moves → device reacts)
- produces an observable signal (sound, motion, or visible signal)
- demonstrates at least one energy transformation
- works repeatedly (at least 2 of 3 trials)
- student can explain the energy pathway
- uses supplied materials and stays within the tabletop test area

# Constraints (limitations)
- only provided materials
- no wall electricity · no open flame · no hot plate · no projectile launching
- limited build time (one period per build/test)
- limited material quantity (kit is finite)
- tabletop footprint limit (e.g., fits on a sheet of paper / tray)

# Testing Cycle
```
PREDICT → BUILD → TEST 1 → OBSERVE (evidence) → CHANGE ONE THING (why) → TEST 2 → COMPARE → EXPLAIN
```
