# CHAPTER 6 DAILY LESSONS — WEEK 8 (Engineering Performance Task)

> Capstone: Tabletop Alert / Signal Device. Aligns to TG Lesson 13 (TG pp. 85–93), AP 13.1–13.6. 45-min blocks; 30-min adjustments noted.

## MONDAY — Problem + criteria + constraints + blueprint (AP 13.1)
**Primary question:** How can I design a device that transforms energy to solve a problem?

1. **Introduce problem (10 min).** *Design a non-electrical tabletop device that produces a clear signal when a model door/gate/trigger moves.* State criteria + constraints (see teacher map).
2. **Brainstorm (10 min).** Groups of 4. Materials on display. Choose one design idea.
3. **Blueprint (20 min).** AP 13.1 — problem, device name, initial/final energy forms, how it transforms energy, "how will you know it works?", criteria, constraints, materials, labeled drawing.
4. **Approval check (5 min).** Teacher initials blueprint ONLY when it has: materials, labels, trigger, output, and an energy-transformation explanation. **No building before approval.**

**30-min note:** Pre-fill criteria/constraints on the board; students copy + draw. Approve during the last 5 min.

## TUESDAY — Build + Test 1 (AP 13.2)
**Primary question:** How can my device be tested?

1. **Recap + safety (5 min).** Review blueprint approval; restate rubber-band safety + tabletop footprint.
2. **Build (20 min).** Groups build their device.
3. **Test 1 (15 min).** AP 13.2 — 3 trials. Record: Did it trigger? What output occurred? Was it clear/reliable? What failed? What evidence did we collect?
4. **Wrap (5 min).** *Initial failure is data, not a penalty.*

**30-min note:** Build in one sitting; run Test 1 (3 trials) in the last 10 min. Save redesign for Wednesday.

## WEDNESDAY — Analyze + redesign + Test 2 (AP 13.2)
**Primary question:** What ONE change should I make, and why?

1. **Analyze Test 1 (10 min).** Groups read their evidence. Identify ONE change based on evidence.
2. **Redesign (10 min).** Record: WHAT WE CHANGED · WHY · PREDICTION.
3. **Test 2 (15 min).** Same 3-trial conditions as Test 1. Record results.
4. **Compare (10 min).** Test 1 vs Test 2. *Did the change help? What is your evidence?* Engineering reasoning matters more than cosmetics.

**30-min note:** Restrict to ONE change; skip the full compare discussion if short on time (do it Thursday).

## THURSDAY — Final explanation + presentation (AP 13.3 + AP 13.4)
**Primary question:** What did I learn about energy transformation and engineering design?

1. **Prepare (10 min).** AP 13.3 — problem, criteria, constraints, blueprint summary, Test 1, redesign, Test 2, energy pathway, final evaluation.
2. **Present (20 min).** Each group presents (~5 min) using AP 13.3. Peers score with AP 13.4.
3. **Summarize (10 min).** Compare transformations across groups; discuss how each device solved the problem.
4. **Reflect (5 min).** One sentence: *What would you change next time, and why?*
