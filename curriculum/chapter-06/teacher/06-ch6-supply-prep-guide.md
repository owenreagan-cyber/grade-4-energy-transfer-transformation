## Safety
- No open flame, no hot plate, no wall electricity, no projectile launching.
- Rubber bands: stretch only; never aim at a person.
- No heavy hanging objects near real doors; the "door" is a tabletop model flap/gate.
- Keep the test area clear; one group tests at a time at the shared trigger station.

## Prep checklist
- [ ] Assemble per-group kits (count items, bag them).
- [ ] Build 1 model trigger (cardboard flap/gate) per station.
- [ ] Set a tabletop footprint guide (sheet of paper or tray) per group.
- [ ] Print AP 12.1, AP 13.1–13.4 (and 13.5/13.6 for flex).
- [ ] Print notebook inserts and engineering performance task pages.

## Cleanup
- Return reusable materials to kits; recycle tape/glue scraps.
- Store model triggers for next year (reusable).

## Failure modes (and fixes)
- **Trigger unreliable** → check the model gate's hinge; keep the same release each trial.
- **Signal too quiet** → add a metal cup or bell as resonator; adjust arm length.
- **Group's device never works** → they still score on design + energy model + evidence-based redesign; provide a provided prototype diagram for absent/struggling groups (see student exemplar).
- **Tape/glue bottleneck** → pre-cut tape strips; limit glue to joints only.

## Quantities
