## Core concept
Energy can **transfer** (move from object to object or place to place) and **transform** (change form). Most systems do **BOTH**. Engineers use energy transformations to solve problems through a **design → build → test → refine** cycle, judging success against **criteria** under **constraints**.

## Chapter 6 boundary (locked)
Chapter 6 teaches **energy transformations + engineering design**. It does NOT require:
kinetic/potential/mechanical/radiant/chemical energy (as required terms) · joules · power · efficiency calculations · voltage/current calculations · electron flow · momentum · force calculations.

## Core model
```
INPUT → CHANGE IN FORM (TRANSFORMATION) → OUTPUT / OBSERVABLE CHANGE
```
```
TRANSFER = energy moves
TRANSFORMATION = energy changes form
BOTH = energy moves AND changes form (may both occur)
```

## Primary ideas (source-verified)
1. Energy can change from one form to another (**transformation**).
2. Energy can move from object to object or place to place (**transfer**).
3. A single system may involve **BOTH**.
4. Engineered devices use energy transformations to solve problems.
5. Success is judged against **criteria** under **constraints**.
6. Engineers **design → build → test → refine**; test results (including failures) are useful evidence.
7. Evidence **supports** an idea (evidence ≠ proof).
