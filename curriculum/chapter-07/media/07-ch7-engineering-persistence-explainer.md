# 07-CH7 MEDIA SCRIPT — EXPLAINER: "How Engineers Learn From Failure"

> Type: EXPLAINER · Role: Persistence / failure-as-data · Status: PENDING (script only)

## The cycle (0:00–0:25)
"Engineers follow a cycle: PROBLEM → DESIGN → TEST → EVIDENCE → IMPROVE."
"A test that doesn't work is NOT the end. It is information."

## Edison's persistence (0:25–0:55)
"Edison tested more than six thousand materials for a light-bulb filament. Most failed."
"He said, 'I haven't failed. I've just found ten thousand ways that won't work.'"
"Each test gave evidence: this material burns too fast, this one costs too much, this one glows just right."

## The rule (0:55–1:15)
"Failure is data. Keep the release setup the same, change ONE thing, and test again."

## Apply it (1:15–1:25)
"Think about your own tabletop device. What did a 'failed' test teach you?"
