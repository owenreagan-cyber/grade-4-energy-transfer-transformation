# CHAPTER 7 DAILY LESSONS — WEEK 9 (Unit Close)

> Edison + engineering persistence → unit synthesis → written final → corrections → Friday close. Aligns to TG Unit Review (pp. 94–98), Reader Ch.7, AP UR.1. 45-min blocks; 30-min options noted.

## MONDAY — Thomas Edison + Engineering Persistence
**Primary question:** How can testing and redesign help engineers solve problems?

- **Objective:** Use Reader Ch.7 to explain Edison's iterative design work (problem → design → test → evidence → improve).
- **Source:** Reader Ch.7 pp. 37–42 · TG pp. 94–98.
- **Materials:** Reader, Core Vocabulary deck, notebook Insert 1.
- **Opening (5 min):** Scavenger-hunt warm-up — find battery-powered devices + lights in the room; ask how each uses transfer/transformation.
- **Instruction (20 min):** Read/discuss Ch.7. Pause: (p.38) Edison did NOT invent the first bulb — he improved it; (p.39) tested 6,000+ materials; (p.40) alkaline battery; (p.41) persistence + Latimer; (p.42) CFL/LED improvements.
- **Notebook (10 min):** Insert 1 — Engineering Is a Cycle; add one Edison example.
- **Formative check (10 min):** Exit: *What evidence shows Edison used testing and redesign?* (not "he invented it alone").

**30-min option:** Skip the scavenger hunt; read pp. 37–39 aloud; notebook insert only.

## TUESDAY — Unit Synthesis
**Primary question:** What have I learned about energy?

- **Objective:** Synthesize the whole unit through retrieval, diagrams, data, and system chains (not pure vocab review).
- **Source:** All chapters; `production/worksheets/07-unit-synthesis-review.docx`.
- **Materials:** Synthesis review, concept-map poster paper/markers, Core Vocabulary deck.
- **Opening (5 min):** Pose the 8 synthesis questions on the board.
- **Instruction (30 min):** Rotate through synthesis stations — concept map (center ENERGY → branches) · retrieval sort (transfer/transformation/BOTH) · graph/data reading · system chains. Use `07-unit-synthesis-review.docx` sections A–J.
- **Notebook (10 min):** Insert 2 — Energy Unit Concept Map; add one example/evidence per branch.
- **Formative check:** Pair-share one branch each.

**30-min option:** Whole-group concept map + 2 stations only; students finish review sheet as homework/Friday.

## WEDNESDAY — Written Final Assessment
**Primary question:** What have I learned about energy? (summative)

- **Objective:** Demonstrate unit learning on the original written final.
- **Source:** `production/quizzes/07-unit-final-assessment.docx` (+ key).
- **Materials:** Final booklets, pencils; optional Core Vocabulary deck (allowed per source).
- **Opening (5 min):** Read directions aloud; show item types (MC, diagrams, data, short answer, CER).
- **Assessment (35–40 min):** Students complete the final. Allow the full block; students who need more time continue Thursday.

**30-min option:** Administer items 1–13 (concepts + data); finish 14–26 Thursday.

## THURSDAY — Complete Final / Corrections / Application
**Primary question:** What did I get right, and what can I correct with evidence?

- **Objective:** Finish the final; then correct errors with evidence (concept repair, not busywork).
- **Source:** `curriculum/chapter-07/student/recovery/07-final-assessment-corrections-recovery.md`.
- **Materials:** Corrections template, keys (teacher-held).
- **Finish (10–15 min):** Students still working complete the final.
- **Corrections (25–30 min):** Students use the template (MISSED ITEM → ORIGINAL THINKING → CORRECT IDEA → EVIDENCE → NEW EXAMPLE). Confer 1:1 with struggling students.
- **Application (5 min):** One engineering/application synthesis prompt (e.g., "explain one energy change in a device you use at home").

**30-min option:** Finish final (15) + corrections on the top 2 missed items only.

## FRIDAY — Recovery / Game / Unit Close
**Primary question:** What did this unit teach me about energy and engineering?

- **Objective:** Recover, practice, and close the unit — no new standard.
- **Source:** `curriculum/chapter-07/student/07-friday-flex-unit-close.md` · AP UR.1 · AP 13.5/13.6.
- **Materials:** Big Questions sheet, review game cards, notebook Insert 3 (Unit Reflection).
- **Recover (optional):** final makeup · missed assessment · notebook completion · absent recovery.
- **Practice:** Energy's Big Questions · cumulative retrieval game · error detective · Transfer/Transformation/BOTH retrieval.
- **Extend:** device mystery · redesign challenge · unit media · showcase reflection.
- **Close (10 min):** Notebook Insert 3 — Unit Reflection.

**30-min option:** one recovery track + one practice game + reflection.
