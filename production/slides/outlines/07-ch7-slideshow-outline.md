### Slide 14 — Review Q1
- **Key text:** "Thomas Edison is best described as someone who —"
  - A. invented the light bulb all by himself · B. improved earlier light bulbs by testing and redesigning · C. only built batteries · D. never tested materials
- **Visual:** HISTORICAL IMAGE.
- **Reveal:** answer next.

### Slide 15 — Q1 Answer
- **Answer:** B. Edison improved earlier designs through testing (6,000+ materials) and redesign.

### Slide 16 — Review Q2
- **Key text:** "Which shows the engineering cycle in the right order?"
  - A. TEST → PROBLEM → DESIGN → IMPROVE → EVIDENCE · B. PROBLEM → DESIGN → TEST → EVIDENCE → IMPROVE · C. DESIGN → EVIDENCE → PROBLEM → TEST → IMPROVE · D. IMPROVE → EVIDENCE → TEST → DESIGN → PROBLEM
- **Reveal:** answer next.

### Slide 17 — Q2 Answer
- **Answer:** B. PROBLEM → DESIGN → TEST → EVIDENCE → IMPROVE.

### Slide 18 — Review Q3
- **Key text:** "A light bulb turns electrical energy into light. This is an example of —"
  - A. energy transfer only · B. energy transformation · C. energy disappearing · D. stored energy doing nothing
- **Visual:** CUTAWAY — bulb.
- **Reveal:** answer next.

### Slide 19 — Q3 Answer
- **Answer:** B. Electrical energy changes form into light — a transformation.

### Slide 20 — Review Q4
- **Key text:** "Why did Edison's team test thousands of materials?"
  - A. to waste time · B. to find evidence for a longer-lasting filament · C. to make the bulb heavier · D. to avoid using the bulb
- **Reveal:** answer next.

### Slide 21 — Q4 Answer
- **Answer:** B. Each test was evidence to improve the design — a longer-lasting filament.

### Slide 22 — Review Q5
- **Key text:** "A design fails a test. An engineer should —"
  - A. stop trying · B. use the failure as evidence and improve · C. hide the result · D. build a bigger version with no change
- **Reveal:** answer next.

### Slide 23 — Q5 Answer
- **Answer:** B. Failure is information — it guides the next improvement.
