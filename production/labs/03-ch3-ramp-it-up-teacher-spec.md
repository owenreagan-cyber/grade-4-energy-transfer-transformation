# Ramp It Up 2.0 — Teacher Spec

Status: REQUIRED. Provenance: ADAPTED from AP 4.1.
Dates: Tuesday 2026-10-20 and Wednesday 2026-10-21.
Materials: cardboard ramp, 3 books, 1 ball, 1 cup, centimeter ruler.

Ramp It Up 2.0 uses one ball. Heights come from 1, 2, and 3 books. Measure the vertical ramp height in centimeters. Measure how far the target moves in centimeters. Run one calibration trial and do not record it. Record three trials at each height. That is nine measured trials. Graph ramp height in centimeters against average target movement in centimeters. Do not write a speed in meters per second. Ramp height is not a measurement of speed. The engineering challenge is to move the target as close as possible to 30 centimeters without going past.

Do not build a second ramp lab. Drop It is Friday FLEX, not this lab.
