# Lab Teacher Spec — Moving Marbles

- **Lab #:** Chapter 2 core investigation (Lab 2 of the 8-lab backbone)
- **Title:** Moving Marbles
- **Chapter/week:** Chapter 2 · Week 2
- **Tag:** CORE
- **Question:** How does a moving marble provide evidence that it has energy?
- **Concept:** a moving object has energy of motion because it can cause change
- **Time:** ~25–30 min (setup + trials + debrief)
- **Prep:** low
- **Cleanup:** collect marbles/trays; collect student pages
- **Group size:** PER GROUP OF 4 (pairs within group work fine)

## Materials
- Identical marbles (1 moving + 1 target per group)
- Flat surface or shallow contained lane / tray edge
- Ruler or tape (optional — measurement is optional evidence, NOT required)
- `02-ch2-moving-marbles-student.docx` (ADAPTED from AP 3.1)

## Consumables
- printed student pages (1/student)

## Safety
- No projectile-style launching; marbles roll in the contained lane; hands dry.
- Supervise so marbles do not leave the table/floor.

## Prediction
- "What do you think will happen when the moving marble reaches the target?"

## Setup constants (identical-object control)
- Same marble type for mover and target (identical marbles).
- Flat, consistent surface each trial.
- One moving marble, one stationary target.
- NO variation of speed, ramp height, or marble mass/type.

## Procedure
1. Place the target marble at rest in the lane.
2. Predict what will happen.
3. Roll the moving marble toward the target (gentle, flat, no ramp).
4. Observe and record: what moved before · what changed after contact · how the target changed · evidence.
5. Repeat 2–3 trials (reset the target each time).
6. (Optional) measure target movement distance with a ruler — NOT required for the concept.

## Evidence collected
- Before/after change of the target (still → moving; position changed).

## Expected pattern
- The target changes position/motion after contact; this is evidence the moving marble had energy of motion.

## Possible unexpected results
- Marble misses target → realign lane.
- Target rolls far away → add a lane edge / cup stop.
- Inconsistent pushes → teacher rolls, or one consistent "gentle push" per group.

## Troubleshooting
| Problem | Fix |
|---|---|
| Marble missing target | realign lane; place target against a lane edge |
| Uneven desk/floor | use a tray or book-spine lane; test first |
| Target rolling too far | add a stop (cup/block) behind target |
| Inconsistent hand pushes | teacher does the roll, or use a "finger-flick" single consistent push |
| Marble leaving table | keep lane short; position away from edges |
| Student competition / launching | reinforce "roll, don't launch"; redirect to observation |

## Debrief questions
- What was moving before contact?
- What changed after contact?
- How does the target's change provide evidence that the moving marble had energy?
- Is "the marble had energy" an observation or an inference?
