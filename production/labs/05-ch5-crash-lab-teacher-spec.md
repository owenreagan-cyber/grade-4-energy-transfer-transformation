# Lab Teacher Spec — Crash Lab (Collisions Transfer Energy)

- **Lab #:** Lab 7 of the 8-lab backbone
- **Title:** Crash Lab — Collisions Transfer Energy
- **Chapter/week:** Chapter 5 · Week 3 (Thu compact investigation)
- **Tag:** CORE
- **Question:** What happens when objects collide, and how are collisions predictable?
- **Big Question:** How is energy involved in collisions? What happens when objects collide?
- **Concept:** A moving object has energy of motion. In a collision, some of that energy transfers to the target, changing the target's motion, and some becomes sound (and a tiny, hard-to-measure bit of heat). Outcomes are predictable when we isolate ONE variable: speed (Part A) or mass/weight (Part B). Students measure TARGET DISPLACEMENT and INFER the energy transfer.
- **Time:** one 30-min block (Thu). **Part A (speed, SAME object) is CORE.** **Part B (mass/weight) is an OPTIONAL extension** — a separate fair test, never combined with Part A in the same test. If time is short, run Part A only.
- **Prep:** moderate (ramps, car sets, release marks)
- **Cleanup:** return cars/ramps/targets; reset lanes
- **Group size:** PER GROUP OF 4

## Materials (per group)
- identical toy cars — same type/size (for Part A) and additional identical cars / taped weights (for Part B)
- ramp (cardboard/wood, ~2 ft)
- books/blocks (3 heights)
- target: plastic cup or small block
- meter stick / ruler (cm)
- tape (release-point + start-line markers)

## Consumables
- printed `05-ch5-crash-lab-student.docx` (1/student) · tape markers

## Safety
- Clear crash lane — no one in the path; cars ROLL (never thrown); fixed release points.
- Newton's cradle = teacher demo only.
- No heat measurement; no open flames.

## Source model (locked)
```
COLLISION → MOTION CAN CHANGE → ENERGY CAN TRANSFER → ENERGY DOES NOT DISAPPEAR
```
Do NOT teach momentum, impulse, force calculations, contact force, deformation, or kinetic/potential/mechanical vocabulary. "Energy of motion" is the ceiling.

## Variable isolation (the heart of the lab)
| Part | Variable changed | Held constant | Measured |
|---|---|---|---|
| **A — Speed** | ramp height (1 / 2 / 3 books) | SAME car, SAME target, SAME surface | target displacement (cm) |
| **B — Mass/Weight** | car mass (1 / 2 / 3 cars taped, or added weights) | SAME ramp height, SAME target, SAME surface | target displacement (cm) |

- **NEVER change speed AND mass at once.** Each part isolates ONE variable.
- Higher ramp → (inferred) faster car; heavier car at same ramp → (inferred) more energy of motion at about the same speed.
- Sound = QUALITATIVE only (louder / quieter / about the same). Heat = NOT measured.

## Procedure — Part A (Speed)
1. **Predict:** "Same car, three ramp heights. At which height will the target move farthest?"
2. **Setup:** ramp at 1 book; target at the end of the lane; tape the start line. SAME car each time.
3. **Test:** release the car from the top of the ramp; measure target displacement (cm). 3 trials per height.
4. **Record:** displacement for 1 / 2 / 3 books; note the sound (qualitative).
5. **Compare:** which height moved the target farthest?
6. **Explain:** higher ramp → faster car → more energy of motion → greater change.

## Procedure — Part B (Mass/Weight) — OPTIONAL extension (separate fair test)
1. **Predict:** "Same ramp, three masses. Which car will move the target farthest?"
2. **Setup:** ramp at a FIXED height; target at the end of the lane. SAME ramp height each time.
3. **Test:** release 1 car, then 2 cars taped, then 3 cars taped (or car + added weights); measure target displacement (cm). 3 trials each.
4. **Record:** displacement for 1 / 2 / 3 masses; note the sound (qualitative).
5. **Compare:** which mass moved the target farthest?
6. **Explain:** same speed, heavier car → more energy of motion → greater change.

## Evidence
- Target displacement (cm) is the primary evidence. Larger displacement = greater energy transferred.
- Sound (qualitative) supports the "some energy becomes sound" idea.
- Students infer the transfer — they never "see energy."

## Expected patterns
- **Part A:** highest ramp → farthest target displacement (faster car → more energy of motion).
- **Part B:** heaviest car → farthest target displacement (same speed, more mass → more energy of motion).

## Possible unexpected results
- Target tips instead of sliding → use a lower target; aim down the lane center.
- Displacement hard to read → tape a start line; keep target in the lane; repeat trials.
- Part A results look flat → confirm the SAME car is used every time; increase the ramp-height spread.
- Part B results look flat → confirm mass actually changes (tape cars firmly); keep ramp height fixed.

## Troubleshooting
| Problem | Fix |
|---|---|
| Target tips over | lower target (cup on its side / low block); center the lane |
| Displacement inconsistent | fixed release point; same release technique; average 3 trials |
| Part A cars differ | use identical cars for the speed test |
| Part B mass doesn't change | tape identical cars firmly (or use identical taped washers) |
| Students say they "measured energy/speed" | redirect: "we measured the target's movement and inferred the rest" |

## Debrief questions
- What changed when the objects collided? (the target moved; we heard a sound)
- Did the energy disappear? (no — it transferred to the target and some became sound)
- For Part A: what did we change? keep the same? measure? (ramp height · car/target/surface · displacement)
- For Part B: what did we change? keep the same? measure? (mass · ramp/target/surface · displacement)
- How is a collision predictable? (same setup → same kind of outcome)
