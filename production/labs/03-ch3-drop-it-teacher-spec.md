# Lab Teacher Spec — Drop It

- **Lab #:** Chapter 3 application investigation (Lab 3b)
- **Title:** Drop It
- **Chapter/week:** Chapter 3 · Week 2 · Friday 2026-10-23
- **Tag:** FLEX (not a first lesson; Ramp It Up 2.0 is the only required investigation)
- **Question:** How does changing the drop height affect the change caused by the same falling object?
- **Big Question:** How are energy and speed related?
- **Concept:** Same as Ramp It Up! 2.0 — for the SAME object, a greater drop height is associated with faster motion and greater energy of motion, shown by a greater observed change (crater width). Students measure the change, NOT speed or energy.
- **Time:** ~20–25 min (setup + trials + recording)
- **Prep:** medium (sand trays)
- **Cleanup:** smooth + cover sand trays; collect pages
- **Group size:** PER GROUP OF 4

## Materials (per group)
- Same ball (identical to Ramp It Up ball)
- Sand tray (shoebox + play sand ~5 lb total)
- Ruler (cm)
- Fixed-height guide marked at 30 cm / 60 cm / (optional 90 cm)
- `03-ch3-drop-it-student.docx` (ADAPTED from AP 4.2)

## Consumables
- printed student pages (1/student)

## Safety
- No throwing sand; drop the ball (never slam); keep faces clear of the tray.
- Smooth the sand between trials so each drop starts from a flat surface.

## Fair test (LOCKED)
- **WE CHANGE:** drop height (30 cm / 60 cm / optional 90 cm).
- **WE KEEP THE SAME:** ball · sand tray · sand surface (re-smoothed) · drop technique.
- **WE MEASURE:** crater width/diameter in cm. Crater depth is **qualitative only** (shallow / medium / deep) — no millimeter precision.

## Prediction
- "At which height will the ball make the biggest crater? Why?"

## Procedure
1. Smooth the sand so there are no dents.
2. Predict the crater size.
3. Hold the ball at 30 cm above the sand (use the height guide); release (no push).
4. Gently lift the ball out; measure the crater width (cm); record Trial 1.
5. Re-smooth; repeat for Trials 2 and 3.
6. Repeat Steps 2–5 at 60 cm (and optional 90 cm).
7. Calculate the average crater width per height; note depth qualitatively.

## Data collected
- Drop height (cm) × crater width (cm) trials → average; qualitative depth note.

## Expected pattern
- Higher drop height → greater average crater width (and a deeper crater). Evidence that the faster-falling ball caused a greater change. The faster motion ↔ greater energy relationship is INFERRED.

## Possible unexpected results
- Crater edges collapse → measure the widest clear edge; re-smooth carefully.
- Ball bounces/rolls → catch/release cleanly; keep the drop vertical.
- Sand too shallow → add sand so a full crater forms without hitting the box bottom.

## Troubleshooting
| Problem | Fix |
|---|---|
| Crater edges collapse | measure the widest clear diameter; re-smooth between trials |
| Ball bouncing | release cleanly (no push); drop straight down |
| Sand too shallow | add sand (~5 lb fills a standard shoebox) |
| Inconsistent heights | use the fixed-height guide every drop |

## Debrief questions
- Which height caused the greatest observable change?
- Did we measure the ball's speed, or the crater it made? (the crater)
- How does this evidence connect to energy of motion? (higher → faster → bigger crater → greater energy of motion, inferred)
