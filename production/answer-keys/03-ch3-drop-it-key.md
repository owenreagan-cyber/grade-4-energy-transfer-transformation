# Answer Key — Drop It

- **Artifact:** `production/worksheets/03-ch3-drop-it-student.docx`
- **Source alignment:** AP 4.2 (Drop It, Day 2); Reader Ch.3 pp. 13–16; TG L4. ADAPTED (fixed cm heights + cm crater width; depth qualitative).

| Item | Correct/expected response | Acceptable alternatives | Reasoning | Common misconception | Scoring note | What NOT to penalize |
|---|---|---|---|---|---|---|
| PREDICT | a guess (e.g., "90 cm makes the biggest crater") | any prediction | prediction = testable guess | wrong prediction = failure | 1 pt | a "wrong" prediction |
| FAIR TEST (change/keep/measure) | change drop height; keep ball/sand tray/surface/drop technique; measure crater width (cm) | paraphrases | fair-test isolation | thinking height = speed (it's a cause, speed is inferred) | 3 pts | informal phrasing |
| DATA TABLE | crater width increases with drop height; averages computed | any internally consistent data | repeated trials + average | recording "energy" in a data cell | 6 pts | noisy crater data |
| OBSERVATION | 60 cm (or 90 cm) caused the greatest change; depth note (medium/deep) | any correct height + qualitative depth | higher → faster → bigger crater | — | 2 pts | depth wording |
| EXPLANATION | higher drop → faster fall (inferred) → bigger crater (measured) → greater energy of motion (inferred) | claim + measured change + inference | change = evidence of energy | claiming we measured energy or speed | 3 pts | informal phrasing |

## Notes
- Crater depth is qualitative only (shallow / medium / deep) — do not require millimeter precision.
- Students must NOT claim they measured the ball's speed or energy. The "faster" determination is an inference from drop height.
- Fixed heights (30/60/90 cm) replace the official knee/waist heights for a fairer test (see `curriculum/chapter-03/source-map.md`).
