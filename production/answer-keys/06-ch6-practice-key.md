# ANSWER KEY — Chapter 6 Practice (Energy Transformations)

## A. TRANSFER / TRANSFORMATION / BOTH
1. Warm water warms a cool spoon → **TRANSFER** (heat moves; form stays heat)
2. Flashlight (stored → light) → **TRANSFORMATION** (or BOTH if the whole flashlight is traced — accept with reasoning)
3. Toy car hits a cup (cup moves + sound) → **BOTH**
4. Buzzer (electrical → sound) → **BOTH** (electrical moves to buzzer AND becomes sound)
5. Falling dominoes (motion passes + click) → **BOTH**

## B. INPUT → CHANGE → OUTPUT
1. Wind-up toy: CHANGE = **stored energy → energy of motion** (energy changes form)
2. Flashlight: CHANGE = **stored energy → electrical → light** (energy changes form)
3. Solar panel: INPUT = **light (sunlight)**
   (Accept: the INPUT is light energy; solar cells transform light → electrical.)

## C. FIX THE ENERGY CHAIN
1. Corrected: **INPUT: stored energy → OUTPUT: sound** (the order was reversed). Accept any answer that puts the input before the output.
