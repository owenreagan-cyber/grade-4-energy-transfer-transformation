# Answer Key — Chapter 2 Practice

- **Artifact:** `production/worksheets/02-ch2-moving-objects-have-energy-practice.docx`
- **Source alignment:** Reader Ch.2 pp. 7–12; TG L3; AP 3.1.

## Part A — What is moving?

| Scenario | Object in motion |
|---|---|
| A basketball falls through the hoop | the basketball |
| A marble rolls toward another marble | the rolled marble |
| Wind spins a turbine blade | the moving air (wind) |
| A shopping cart bumps a box | the shopping cart |

## Part B — What changed?

| Scenario | Change caused |
|---|---|
| The basketball hits the net | the net moves (still → moving) |
| The marble hits the target marble | the target changes position |
| Wind spins the blades | the blades rotate (still → spinning) |
| The cart bumps the box | the box slides forward |

## Part C — Evidence (which observation shows the moving object had energy?)

| Observation | Evidence? | Why |
|---|---|---|
| "The target marble changed position." | YES | a change happened caused by the mover |
| "The marble is round." | NO | shape is not a change caused by motion |
| "The block slid forward after the ball hit it." | YES | still → moving is a change |
| "I think the ball is heavy." | NO | opinion, not an observed change |

## Part D — Before / After (sample)
- Before: target block still. After: block moved. Arrows show the direction of the moving object and the target's motion.
- Accept any correct two-frame drawing with a clear change.

## Part E — Explain (sample)
"A moving object has energy of motion. When it bumps another object and that object changes position, the change is evidence that the moving object had energy."

- Accept any response that (a) states a moving object has energy of motion, (b) names an observed change, (c) links the change to energy as evidence.
- Do NOT require speed/fast-slow language.
