# UNIT 2 ABSENT-RECOVERY INDEX

> **Teacher-only reference.** One place to find the minimum recovery work for any missed Unit 2 lesson (Weeks 5–8.5).
> **Principle:** absent work is *lighter* than live-class work. A student never has to rebuild a physical lab.
> For labs, the preferred path is: **inspect provided data → complete the analysis → view the setup diagram → finish the pathway/reflection.**
> **Makeup tiers:** ESSENTIAL (must be done before rejoining the concept) · RECOMMENDED (do if time) · OPTIONAL (may skip safely).
> Companion: `UNIT2_ABSENT_RECOVERY_INDEX.md` ↔ `TEACHER_PREP_GUIDE.md` "Absent:" lines. Student-facing sheets stay in `production/premium-notes/unit-02/` and `production/activities/unit-02/`.

---

## How to use this index

1. Find the missed **week/day** below.
2. Give the student the listed **makeup path** (a notes page, a self-contained activity, or provided partner data).
3. Use the **substitute assignment** if a hands-on activity cannot be recreated.
4. Mark the Science Journal line only when a reflection is genuinely useful — most makeup can skip it.

> Reading pages refer to the Unit 2 Student Reader (`assets/authoritative/unit-02/student-reader/chapters/`).

## Absent-student quick rules

- **Never** require a missed-lab student to rebuild a ramp, wheel, or solar kit alone.
- **Always** offer partner/class data before a substitute assignment for labs.
- **Priority order** for makeup: (1) notes page with the key idea → (2) self-contained activity → (3) provided lab data + analysis → (4) optional journal reflection.
- **Assessment:** give `unit2-written-study-review.docx` before the make-up, never as a surprise.
- **Science Journal reflection** is only required when the day's live class relied on it; otherwise it is optional.
