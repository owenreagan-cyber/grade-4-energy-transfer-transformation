# UNIT 1 ASSESSMENT — ADMINISTRATION NOTE (TIMING / SPILLOVER)

> **Teacher-only.** The Unit 1 final assessment (`production/quizzes/07-unit-final-assessment.docx`, 25 items · 50 points · matching + multiple choice) takes **≈30–35 minutes**, fitting the daily **30-minute** block with a small optional spillover.
> All items are objective (selected-response); there are no written-response, CER, or diagram-labeling items to administer orally.
> Scoring key: `production/quizzes/07-unit-final-assessment-key.docx` · scoring guide: `production/quizzes/07-unit-final-assessment-scoring-guide.md`.

---

## At a glance

| Path | When to use | What changes | Science coverage |
|---|---|---|---|
| **Option A — 30-min block + spillover** | default (preferred) | split administration across two blocks | full, unchanged |
| **Option B — single 30-min block** | tight schedule / many accommodations | students finish at their own pace; late finishers complete during spillover | full, unchanged |

---

## OPTION A — 30-MINUTE BLOCK + SPILLOVER (default)

**Day 1 (assessment start, 30 min):**
- 0–2 min — distribute, read directions aloud.
- 2–28 min — students complete **Part 1: Matching (Q1–8)** and begin **Part 2: Multiple Choice (Q9–25)**.

**Natural stop point:** end of the 30-minute block. All items are selected-response, so any unfinished multiple-choice questions continue next block.

**Next available block / Friday continuation:**
- 0–15 min — finish remaining multiple-choice questions (Q9–25).
- 15–25 min — **corrections** against the key if time remains (self-contained; no new teaching).

**Collection procedure:** collect papers at the stop point; keep them in the same folder with names/periods; return the *same* papers at the continuation — do **not** photocopy or redistribute to a different student.

**Restart procedure:** hand back each student's own paper, re-read the remaining item stems aloud, and resume. No new time bonus needed; the split is already built into Option A.

---

## OPTION B — SINGLE 30-MINUTE BLOCK

All items are selected-response, so no item requires oral administration. Students work front-to-back; any who do not finish continue during the regular spillover window (or a brief next-block continuation as in Option A).

---

## Shared details (both options)

- **Estimated completion time:** ≈30–35 minutes written (full).
- **Accommodations:** extended time = finish during spillover (Option A); scribe = student dictates the letter, adult writes; Core Vocabulary card use is already allowed.
- **Absent-student path:** make-up block using Option A; offer `production/worksheets/07-unit-synthesis-review.docx` + `07-energy-big-questions.docx` (keys in `production/answer-keys/`) as optional review beforehand. Never split the assessment across more than two blocks.
- **Do NOT** pack the Rube Goldberg extension into the assessment block; it is a separate Friday FLEX activity.
