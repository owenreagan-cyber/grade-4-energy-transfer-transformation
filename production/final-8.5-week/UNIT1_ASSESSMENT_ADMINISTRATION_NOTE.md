# UNIT 1 ASSESSMENT — ADMINISTRATION NOTE (TIMING / SPILLOVER)

> **Teacher-only.** The Unit 1 final assessment (`production/quizzes/07-unit-final-assessment.docx`, 26 items · 50 points) takes **≈35–40 minutes**, but the daily block is **30 minutes**.
> This note removes the need to improvise. It does **not** rebuild or shorten the assessment's science coverage.
> Scoring key: `production/answer-keys/07-unit-final-assessment-key.md` · scoring guide: `production/quizzes/07-unit-final-assessment-scoring-guide.md`.

| Path | When to use | What changes | Science coverage |
|---|---|---|---|

## OPTION A — 30-MINUTE BLOCK + SPILLOVER (default)

**Day 1 (assessment start, 30 min):**
- 0–2 min — distribute, read directions aloud, remind "evidence, not proof."
- 2–27 min — students complete **selected-response and core items** (Items 1–2, 5–6, 8–10, 12–15, 17–18, 20–22, 25 — the MC / select-all / classify / data-table / matching items).
- 27–30 min — students complete any **short written items** they reach (Items 4, 7, 11, 19, 26). Do **not** rush the CER (Item 23) or the three diagram items (3, 16, 24) here.

**Natural stop point:** after the matching/classify block (Item 22). Everything before this is the "core."

**Next available block / Friday continuation:**
- 0–15 min — finish **short response + diagram items** (3, 16, 23, 24) and any core items still open.
- 15–25 min — **corrections** against the key if time remains (self-contained; no new teaching).

**Collection procedure:** collect papers at the stop point; keep them in the same folder with names/periods; return the *same* papers at the continuation — do **not** photocopy or redistribute to a different student.

**Restart procedure:** hand back each student's own paper, re-read the remaining item stems aloud, and resume. No new time bonus needed; the split is already built into Option A.

---

## OPTION B — TRIMMED CLASSROOM ADMINISTRATION (oral, not omitted)

If you must finish in one 30-min block, convert these **four items to oral completion** — the test paper itself is **unchanged**, and no science coverage is lost:

| Item | Type | Oral completion |
|---|---|---|
| 3 | diagram (energy causes change) | student **describes** the before→after change and names the energy form aloud (1–2 sentences) |
| 16 | diagram (input/output) | student **says** the INPUT → TRANSFORMATION → OUTPUT chain aloud |
| 24 | diagram (device energy chain) | student **says** the chain aloud (e.g., "electrical → motion") |
| 23 | CER | student gives the **claim + one piece of evidence + reasoning** in one spoken sentence |

**What is NEVER treated as optional/bonus:** the matching, MC, select-all, classify, data-table, graph, fair-test, and engineering-application items (1–2, 4–8, 9–14, 15, 17–22, 25–26). These carry the core scientific coverage.

**Timing under Option B (single 30-min block):**
- 0–2 min — directions.
- 2–24 min — written items (all but 3, 16, 23, 24).
- 24–30 min — pull 3–4 students aside in turn for the oral items while others finish/check.

## Shared details (both options)

- **Estimated completion time:** ≈35–40 min written (full); ≈30 min with Option B orals.
- **Accommodations:** extended time = finish during spillover (Option A); oral responses = Option B; scribe = student dictates, adult writes; Core Vocabulary card use is already allowed.
- **Absent-student path:** make-up block using Option A; offer `production/worksheets/07-unit-synthesis-review.docx` + `07-energy-big-questions.docx` (keys in `production/answer-keys/`) as optional review beforehand. Never split the assessment across more than two blocks.
- **Do NOT** pack the Rube Goldberg extension into the assessment block; it is a separate Friday FLEX activity.
