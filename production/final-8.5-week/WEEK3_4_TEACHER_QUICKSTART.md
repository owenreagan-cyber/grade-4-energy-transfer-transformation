# Week 3–4 Teacher Quickstart

> Unit 1 · Ch4 Energy Transfer · Ch5 Collisions · Ch6 Energy Transformations · Ch7 Edison + synthesis.
> 30-min blocks · 20 students · 5 groups of 4 · Thursday = action/lab · Friday = flex.

---

## WEEK 3 — Ch4 (Energy Transfer) + Ch5 (Collisions)

### Monday — Transfer intro (sound + light)
- **OPEN** `04-ch4-energy-transfer-slides.pptx` (S1–S19).
- **PRINT** `04-ch4` guided notes p.1–2 (1/student).
- **GATHER** paper target, plastic cup, tapping stick; flashlight + index-card target + a barrier (book).
- **TEACH** cup-tap → paper moves (hook) → Big Question → transfer definition → sound investigation → light + barrier test → SOURCE → ENERGY MOVES → TARGET CHANGES.
- **STOP-HERE-IF-SHORT** skip the barrier test; keep the transfer definition + one evidence example.
- **ABSENT** `04-ch4` p.1–2 (self-contained).

### Tuesday — Heat + electric current
- **OPEN** `04-ch4-energy-transfer-slides.pptx` (S24–S35).
- **PRINT** `04-ch4` p.3.
- **GATHER** warm (NOT hot) water + thermometers; AA/AAA battery + wires + bulb/buzzer (low voltage only — no wall outlets, no coin cells).
- **TEACH** heat (warm water → cool cup, °C) → electric current (complete/broken circuit) → BATTERY → CIRCUIT → DEVICE → CHANGE.
- **STOP-HERE-IF-SHORT** keep heat; make the circuit a quick demo.
- **ABSENT** `04-ch4` p.3.

### Wednesday — Collisions (before/during/after)
- **OPEN** `05-ch5-collisions-slides.pptx` (S1–S12).
- **PRINT** `05-ch5` p.1.
- **GATHER** Newton's cradle (optional teacher demo).
- **TEACH** collide/collision → before/during/after → motion/shape/sound changes → SAME object, faster = more energy of motion. Keep mass as a *separate* idea (S11).
- **STOP-HERE-IF-SHORT** definition + motion change + energy-doesn't-disappear.
- **ABSENT** `05-ch5` p.1.

### Thursday — Compact Crash Lab (Part A only)
- **OPEN** `05-ch5-collisions-slides.pptx` (S13–S18).
- **PRINT** `05-ch5-crash-lab-student` (1/student) + have `05-ch5-crash-lab-teacher-spec` open.
- **GATHER** 5 stations: identical toy car, ramp, 3 books (heights), cup/block target, ruler (cm), tape.
- **TEACH** 0–4 launch/safety → 4–20 roll SAME car at 1/2/3 heights, 3 trials, measure target displacement → 20–25 cleanup → 25–30 exit.
- **STOP-HERE-IF-SHORT** run 1 and 3 heights only (skip middle).
- **ABSENT** give partner/class data (see spec absent-recovery).

### Friday — Recover / Practice / Extend
- **OPEN** `04-ch4` S36–S40 (sort) + `05-ch5` S24–S27 (collision review).
- **GATHER** `transfer-transformation-both-sort` cards + mat (laminate once).
- **TEACH** finish lab → Transfer/Transformation/BOTH sort → collision review. No new content.
- **ABSENT** sort cards are self-contained.

## WEEK 4 — Ch6 (Transformations) + Ch7 (Edison + synthesis)

### Monday — Transformations (input/output)
- **OPEN** `06-ch6-energy-transformations-slides.pptx` (S1–S23).
- **PRINT** `06-ch6` p.1–2.
- **GATHER** wind-up toy; flashlight, buzzer, small motor/fan (for the device survey).
- **TEACH** wind-up hook → transform vs transfer → flashlight/buzzer/motor chains (INPUT → TRANSFORMATION → OUTPUT) → device survey → Transfer/Transformation/BOTH.
- **STOP-HERE-IF-SHORT** flashlight chain + one "BOTH" example.
- **ABSENT** `06-ch6` p.1–2.

### Tuesday — Criteria / constraints / engineering cycle
- **OPEN** `06-ch6-energy-transformations-slides.pptx` (S24–S34).
- **PRINT** `06-ch6` p.3.
- **GATHER** none (brainstorm only).
- **TEACH** engineering design (Reader p.36) → vocabulary → design bridge ("signal without wall electricity") → problem + criteria + constraints + materials.
- **STOP-HERE-IF-SHORT** criteria + constraints only (skip materials brainstorm).
- **ABSENT** `06-ch6` p.3.

### Wednesday — Edison / Latimer / iteration
- **OPEN** `07-ch7-edison-unit-synthesis-slides.pptx` (S1–S12).
- **PRINT** `07-ch7` p.1.
- **GATHER** none.
- **TEACH** improve-don't-invent → 6,000 materials → 1879 bamboo/carbon → filament → persistence → Latimer → engineering cycle.
- **STOP-HERE-IF-SHORT** improve-don't-invent + testing → redesign (skip alkaline battery).
- **ABSENT** `07-ch7` p.1.

### Thursday — Device Energy Chain / engineering application
- **OPEN** `06-ch6-energy-transformations-slides.pptx` (S29–S44).
- **PRINT** `06-ch6` p.4 (+ optional `06-ch6-engineering-performance-task` pp.1–2 + one test page).
- **GATHER** craft bins: cardboard tubes, paper cups, craft sticks, rubber bands, string, paper clips, washers, bell, tape, blocks, foil. Non-electrical; no wall outlet/flame/hotplate/launching.
- **TEACH** 0–5 problem/criteria/constraints → 5–20 build + Test 1 (3 trials) → 20–25 cleanup → 25–30 redesign note ("one change + why").
- **STOP-HERE-IF-SHORT** build + one test only; redesign note verbal.
- **ABSENT** `06-ch6` p.4 + prototype-diagram path (see spec).

### Friday — Unit 1 assessment / corrections / extension
- **OPEN** `07-ch7` S24–S26 (assessment expectations + correction process).
- **PRINT** `07-unit-final-assessment` (1/student) + `07-unit-final-assessment-key` (teacher).
- **GATHER** Core Vocabulary cards (if allowed); correction sheets.
- **TEACH** assessment as a dedicated block — allow spillover into the next block; do NOT pack the Rube Goldberg extension with it.
- **STOP-HERE-IF-SHORT** give assessment; skip extension.
- **ABSENT** assessment can be completed in a make-up block; corrections self-contained.
