# WEEK 1–2 TEACHER QUICKSTART

> At-a-glance daily plan for the first two weeks. Use with `ENERGY_AND_NATURAL_RESOURCES_MASTER_PACING.md`,
> `PRINTING_GUIDE.md`, and `TEACHER_PREP_GUIDE.md`. 20 students · 5 groups of 4 · ~30-min blocks.
> **Print once Sunday:** `01-ch1` (3 pp) · `02-ch2` (2 pp) · `03-ch3` (3 pp) · Moving Marbles (2 pp) ·
> Ramp It Up (3 pp) · Fast & Curious (Fri). 20 copies each.

---

## WEEK 1

### Mon — Energy causes change
- **Open:** `01-ch1` deck (slides S1–S9).
- **Print:** `01-ch1` GN p.1 (already printed).
- **Gather:** projector only.
- **Teach:** title → dark/light hook → Big Question → "energy = ability to cause change" → change = evidence.
- **Students write:** GN p.1 (key words, model, before/after drawing).
- **Exit:** name one change + its evidence.
- **Stop if short:** drop S5 ("what counts as change").
- **Absent:** send GN p.1 + journal prompt.

### Tue — Stored energy / forms
- **Open:** `01-ch1` deck (slides S12–S23).
- **Print:** GN p.2.
- **Gather:** flashlight + battery (battery **in a device**, not alone); optional sort cards.
- **Teach:** 5 forms → forms check → stored energy (predict → reveal) → raised object.
- **Students write:** GN p.2 (forms table, stored-energy table, stored-energy drawing).
- **Exit:** stored-energy table check.
- **Stop if short:** drop S18 forms check.
- **Absent:** send GN p.2.

### Wed — Moving objects have energy
- **Open:** `02-ch2` deck (slides S1–S13).
- **Print:** `02-ch2` GN p.1.
- **Gather:** projector.
- **Teach:** marble hook → prediction → Big Question → motion → energy of motion.
- **Students write:** GN p.1 (motion + energy-of-motion fill-ins, model).
- **Exit:** "energy of motion" fill-in.
- **Stop if short:** drop S12–S13 (notes cues) to Thursday.
- **Absent:** send GN p.1.

### Thu — Moving Marbles investigation
- **Open:** `02-ch2` deck (slides S14–S24).
- **Print:** Moving Marbles student sheet (2 pp).
- **Gather:** identical marbles, cups, flat lane/tray, ruler (optional).
- **Teach:** launch → setup → predict → 3 trials → record → debrief (observation vs inference).
- **Students write:** observation/evidence table (keep writing light during hands-on).
- **Exit:** "the target's change is evidence the marble had energy."
- **Stop if short:** skip S22–S23 (examples/non-example).
- **Absent:** partner data + GN p.2.

### Fri — FLEX
- **RECOVER:** Energy Detectives catch-up (finish GN p.3 evidence table).
- **PRACTICE:** Energy Charades (motion/sound/light/heat/electrical/stored).
- **EXTEND:** journal drawing of one energy change.
- No new content.

## WEEK 2

### Mon — Same-object speed relationship
- **Open:** `03-ch3` deck (slides S1–S9).
- **Print:** `03-ch3` GN p.1.
- **Gather:** projector.
- **Teach:** same-object reminder (SAME ball, SAME target) → prediction → Big Question → speed def → slow/fast arrows (a model, not a measurement).
- **Students write:** GN p.1 (speed fill-in + "SAME object" key idea).
- **Exit:** "SAME object" highlight check.
- **Stop if short:** drop S8–S9 (speed def + arrows).
- **Absent:** send GN p.1.

### Tue — Fair test / ramp setup
- **Open:** `03-ch3` deck (slides S10–S14).
- **Print:** GN p.2.
- **Gather:** ramp boards/books, ONE identical ball type, cups, ruler, tape.
- **Teach:** fair test → variables (change ramp height; keep ball/cup/surface) → setup.
- **Students build:** 5 ramp stations (1/2/3 books) — keep for Thursday.
- **Exit:** fair-test verbal check.
- **Stop if short:** build stations in the last 10 min only.
- **Absent:** send GN p.2.

### Wed — Prediction / data table setup
- **Open:** `03-ch3` deck (slides S15–S19).
- **Print:** Ramp It Up student sheet (3 pp).
- **Gather:** data sheets, pencils.
- **Teach:** predict → procedure (release, no push) → **optional WATCH S17 (2:29 "Ramp It Up in Action")** → data table (3 heights × 3 trials) → graph axes.
- **Students write:** prediction + set up data table + measured vs inferred (GN p.2–3).
- **Exit:** data-table setup check.
- **Stop if short:** move graph setup (S19) to Friday.
- **Absent:** send GN p.3.

### Thu — FLAGSHIP LAB: Ramp It Up!
- **Open:** `03-ch3` deck (slides S16 + S18 as reference — procedure + data table).
- **Print:** Ramp It Up sheet (already handed out Wed). **Setup diagram:** `production/lab-setup-guides/ramp-it-up-setup-guide.docx` (laminate).
- **Gather:** stations from Tue + balls + cups + rulers.
- **Run:** 0–4 launch/safety → 4–20 trials (3 heights × 3 trials) → 20–25 cleanup → 25–30 data check.
- **Students write:** trials + averages (light writing; measure, don't narrate).
- **Exit:** initial data check (did higher ramp move the cup farther?).
- **Stop if short:** reduce to 2 trials/height **only if necessary** (still valid).
- **Absent:** partner data.

### Fri — Ramp analysis
- **Open:** `03-ch3` deck (slides S19–S24) for averages, graph, measured vs inferred.
- **Print:** graph paper.
- **Gather:** collected data sheets.
- **Do:** averages → graph (Ramp Height vs Average Cup Displacement) → claim/evidence.
- **EXT:** Fast & Curious (ramps + balls + cups) if time allows.
- **RECOVER:** measured vs inferred reteach for a small group.
- **Absent:** Fast & Curious sheet is self-contained.
