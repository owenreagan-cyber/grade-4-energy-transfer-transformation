# LAB QA CHECKLIST

> Run against every lab (teacher + student pages) before it can pass QA.

- [ ] Question matches the Big Question
- [ ] Target concept correct (source-aligned)
- [ ] One variable changed / controlled factors stated (fair test)
- [ ] Primary evidence is measurable & answers the question
- [ ] Materials safe, low-prep, reusable-heavy (end-of-day prep)
- [ ] Safety notes complete (no wall outlets / no default hot plate)
- [ ] Prep / cleanup clear
- [ ] Absent-student recovery documented
- [ ] Likely failure modes + troubleshooting noted
- [ ] No mass+speed confound (same object for speed-energy)
- [ ] No advanced vocabulary (kinetic/potential/compression-wave/etc.)
- [ ] Student page reveals no expected results
- [ ] CER only where appropriate (not forced identically every lab)

Result: PASS / WARN / FAIL
