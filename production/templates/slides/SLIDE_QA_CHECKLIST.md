# SLIDE QA CHECKLIST

> Run against every slide deck before it can pass `VISUAL_LAYOUT` + `EDUCATIONAL_SUITABILITY` gates.

- [ ] One primary idea per slide
- [ ] Projection readability (large type; visible from back of room)
- [ ] Minimal text (no wall of paragraphs)
- [ ] Clear image/diagram purpose (each visual earns its place)
- [ ] No decorative clutter
- [ ] No source drift (matches authoritative wording/concept)
- [ ] No vocabulary introduced too early (respects `VOCABULARY_PROGRESSION.md`)
- [ ] No cropped/off-screen content
- [ ] Consistent navigation (title/big-question/question-to-answer rhythm)
- [ ] Lab slides distinct from teaching slides
- [ ] Prediction prompts reveal **after** the question (not simultaneous)
- [ ] Grade 4 language; no kinetic/potential/radiant/compression-wave/inertia as required

Result: PASS / WARN / FAIL
