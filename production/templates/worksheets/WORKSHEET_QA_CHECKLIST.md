# WORKSHEET QA CHECKLIST

> Run against every worksheet/activity page before it can pass QA.

- [ ] Sufficient writing space (Grade 4)
- [ ] Table readability (no cramped columns/rows)
- [ ] No over-compressed one-page requirement (multiple pages allowed)
- [ ] Age-appropriate language
- [ ] Observed vs inferred distinction where relevant
- [ ] Source alignment (concepts/vocab match authoritative source)
- [ ] No prefilled experimental result (no answer leakage)
- [ ] Printable grayscale performance (colors degrade gracefully)

Result: PASS / WARN / FAIL
