# QUIZ STANDARD

> Chapter quiz spec. Target: **10–15 minutes**.

## Recommended balance
- ~**50%** current concept
- ~**25%** application / data
- ~**25%** spiral review

## Item types to USE
- scenarios (energy in a real situation)
- simple diagrams (label the energy flow)
- data (read a table/graph)
- evidence (what does this change tell us?)
- short explanation

## AVOID
- vocabulary-only quizzes (assess **in context**, not isolated matching)
- trick wording
- advanced terminology (kinetic/potential/radiant/compression-wave/inertia)
- measuring reading difficulty more than science
- mass + speed confounds (use the **same object** for speed–energy items)

## Alignment
- shares Big Question, vocabulary, and model with notes/slides/final test.
- answer key is separate (see `TEACHER_KEY_STANDARD.md`).
