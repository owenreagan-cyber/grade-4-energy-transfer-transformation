# SLIDE DECK STANDARD

> Slides support science; they do **not** replace investigation.

## Rules
- **one core instructional idea per slide**
- large, classroom-readable type
- minimal paragraphs (no walls of text)
- strong visuals
- diagrams / arrows / models (use the unit energy-flow model)
- **prediction prompts** (pause before reveal)
- **reveal sequences** (don't show the answer with the question)
- student discussion prompts
- ready-to-project lab directions
- timers **only** when useful
- avoid decorative clutter

## Two kinds of decks (separate)
- **TEACHING SLIDES** — concepts, discussion, reading support
- **LAB / ACTIVITY SLIDES** — directions, safety, data tables, timers

## QA checklist (applies to every deck)
- one idea per slide
- readable projection size
- no crowded paragraphs
- visual clarity
- no off-screen / cutoff content

## Alignment
Slides share the same Big Question, vocabulary, and model as notes/quiz/final (see `STUDENT_NOTES_STANDARD.md`).
