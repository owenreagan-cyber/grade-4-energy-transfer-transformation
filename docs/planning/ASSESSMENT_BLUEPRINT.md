# ASSESSMENT BLUEPRINT

> Full assessment system for the unit. Emphasizes **Week 8 = performance**, **Week 9 = written** — students are **not** required to build a second device during the written test.

## System overview

| Layer | Instrument | Frequency | Timing |
|---|---|---|---|
| **Daily** | checks for understanding · exit tickets · notebook checks · teacher observation | daily | 3–5 min |
| **Chapter** | short chapter quiz (10–15 min) | per chapter | end of each chapter |
| **Formative checkpoints** | larger checkpoint | 3× | after Ch.1–3, Ch.4–5, Ch.6–7 |
| **Performance** | Engineering Capstone (Week 8) | 1× | Week 8 |
| **Summative** | Written unit assessment (Week 9) | 1× | Week 9 |

## Chapter quizzes (see `QUIZ_STANDARD.md`)
- 10–15 min target
- ~50% current concept · ~25% application/data · ~25% spiral review

## Formative checkpoints
- **After Ch.1–3:** energy-as-change, forms of energy, motion energy, speed-energy (same object).
- **After Ch.4–5:** transfer evidence (sound/light/heat/electricity), collision transfer.
- **After Ch.6–7:** transformation, engineering design, synthesis.

## Performance assessment (Week 8)
- Engineering Capstone rubric (problem understanding, criteria/constraints, energy model, testing, evidence, redesign, explanation). See `ENGINEERING_CAPSTONE.md`.

## Written summative (Week 9) — content requirements
The final must include:
- vocabulary **in context** (no isolated matching)
- diagrams / models
- data / graph interpretation
- transfer / transformation / **BOTH**
- speed–energy reasoning using the **same object**
- collision prediction
- CER (Claim, Evidence, Reasoning)
- engineering / application

## What to AVOID (explicit)
- excessive matching
- advanced vocabulary not required in the unit (kinetic, potential, radiant, compression wave, inertia)
- **mass + speed confound** in core speed questions (compare same object only)
- binary transfer/transformation questions when the scenario is actually **BOTH**

## Key separation
- Student test and teacher key are **separate files** (never mixed into the student PDF).
- Weighting / gradebook integration remains OPEN (see `OPEN_QUESTIONS.md`).
