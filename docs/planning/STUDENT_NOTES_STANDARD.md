# STUDENT NOTES STANDARD

> Guided notes are a **scaffold for thinking**, not a copy of the Reader.

## Rule
Notes must **NOT** copy the Student Reader. They capture student thinking, evidence, and models.

## Default notes page includes
1. **Big Question** (top, visible)
2. **3–5 essential ideas** (fill-in, short)
3. **Limited vocabulary** (current chapter only)
4. **One visual model**
5. **One diagram / energy-flow chain** (`SOURCE → FORM → TRANSFER → TRANSFORMATION → EVIDENCE`)
6. **Example / non-example**
7. **Conclusion / evidence box** ("What changed, and what does that tell us about energy?")
8. **Cumulative retrieval question** (spiral from prior chapters)

## Qualities
- concise · writable · visually spacious (Grade 4 handwriting space)
- useful during review
- **aligned** to slides · quiz · final test (same Big Question, same vocabulary, same model)

## Non-negotiables
- Grade 4 terminology only (no kinetic/potential/radiant/compression-wave/inertia as required).
- Distinguish observation from inference.
- One model/diagram minimum per notes page.
