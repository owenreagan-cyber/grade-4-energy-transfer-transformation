# WHOLE-UNIT MEDIA STAGING

> Phase 10. A media library is NOT a viewing schedule. Each video is classified CORE / SUPPORT / FLEX and given a recommended slot. Chapters 3–7 have no generated videos yet → `PENDING GENERATION` placeholders only (do NOT invent files). No MP4 is embedded in any PPTX; all playback is local file reference.

## Legend
- **CORE** = meaningfully improves essential instruction (max 0–1 per lesson).
- **SUPPORT** = useful but optional.
- **FLEX** = enrichment / review / recovery / bell-ringer.
- **Status:** `STAGED` · `UNSTAGED` · `PENDING GENERATION`.
