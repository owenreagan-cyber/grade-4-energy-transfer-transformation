# NOTEBOOK ABSENT STUDENT WORKFLOW

> How an absent student receives notebook content without fabricating first-person observations.

## Standard hand-off (teacher, ~2–3 min)
1. **Missed insert** — place the chapter notebook insert(s) in the student's notebook folder/return slot.
2. **Completed slide model** — provide the printed notebook-cue slide(s) or the teacher-completed model page so the student can copy the essential wording.
3. **Investigation data** — provide the class/sample data table (from the chapter recovery guide) if the missed day included a lab.
4. **Optional pre-cut interactive piece** — provide a pre-cut flap/foldable so the student can glue without cutting.

## Wording rule
- Use "Our class observed…" / "Use the class data below…" — never imply the absent student performed the observation.

## Recovery pathway (matches chapter recovery guides)
1. Read the selected Reader pages.
2. Review the setup diagram.
3. Use the class/sample observations.
4. Answer the analysis questions.
5. Complete the chapter model (e.g., `ENERGY → CHANGE → EVIDENCE`).

## Distribution timing
- Same day if possible; otherwise the next science class during the RECOVER slot (Friday Flex).

## Do NOT
- Require the absent student to redo the lab alone.
- Require the interactive cut for credit if motor support is unavailable (flat alternative is always acceptable).
