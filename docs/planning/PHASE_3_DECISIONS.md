# Phase 3 Decisions

> Every standard change made during Phase 3, with status LOCKED / REVISED / OPEN. No silent changes.

## LOCKED
- **Quiz length/balance:** 8–12 items, 10–15 min, ~50% core / ~25% application / ~25% evidence reasoning; Chapter 1 uses no artificial prior-unit spiral.
- **Friday Flex structure:** 3 tracks — RECOVER / PRACTICE / EXTEND — with no Week-2 dependency.
- **No PE on Part A:** Lessons 1–2 carry no Performance Expectation (source-faithful).
- **Terminology ban:** kinetic, potential, gravitational potential, mechanical, radiant, compression wave, inertia — excluded from all student-facing artifacts.
- **evidence = Language of Instruction** (not Core Vocabulary) — preserved in source map and all keys.

## REVISED
- **Slide density standard:** one core idea per slide; ≤3 short bullets on direction/lab slides; prediction-before-reveal for demo slides.
- **Writing-space standard:** ruled answer lines for Grade 4; ≥2 lines for explain prompts; no paragraph copying.
- **Table standards:** min row height 0.5" (portrait) / 1.1" (landscape investigation tables); shaded header row.
- **Detectives student page:** ADAPTED from AP 1.1 (2 columns) → full 6-column evidence model (Object/Before/After/Change/Evidence/Form), landscape.

## OPEN
1. **Class/group count** — unresolved; supply quantities remain `GROUP_COUNT × amount`.
2. **Quiz scoring denominator** — item points set; denominator per school grading policy.
3. **External media verification** — rocket-launch + extension videos are candidates, not verified.
4. **Placeholder visuals vs. photos** — slides use text/shape diagrams; photo sourcing deferred to a later phase.
