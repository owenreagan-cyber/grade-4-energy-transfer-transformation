# DAILY LESSON ARCHITECTURE

> Default Monday–Thursday rhythm. Days are **not** forced into one template — choose the option that fits the learning goal. All times assume a ~40–45 min period; scale proportionally.

## Guiding principle
The preferred science flow is:
**phenomenon → prediction → investigation/observation → evidence/data → discussion → reading/notes → explanation/application.**

Slides, notes, and worksheets are supports; **investigation leads**, reading confirms.

---

## OPTION A — STANDARD CONCEPT DAY
1. **Retrieval / Hook / Phenomenon** — 5 min
2. **Prediction / discussion** — 5 min
3. **Investigation / demo / activity** — 15–20 min
4. **Analyze evidence** — 8–10 min
5. **Reader / guided notes** — 8–10 min
6. **Exit / check for understanding** — 3–5 min

## OPTION B — LAB DAY
1. **Question / prediction**
2. **Safety / setup**
3. **Investigate**
4. **Collect data**
5. **Quick debrief**
6. **Complete analysis later if needed** (never rush evidence into a forced conclusion)

## OPTION C — READING / SYNTHESIS DAY
1. **Retrieve prior evidence**
2. **Reader section**
3. **Discussion / misconception check**
4. **Visual model**
5. **Guided notes**
6. **Application**

## OPTION D — ASSESSMENT DAY
1. **Short retrieval**
2. **Quiz / checkpoint**
3. **Corrections / analysis**
4. **Extension if time**

---

## Non-negotiables (all options)
- Every day ends with a **check for understanding** (exit ticket, quick write, notebook, or observation).
- The **Big Question** is visible and revisited (open → investigate → answer).
- Students distinguish **observation** from **inference** ("Observed: cup moved 22 cm. Inferred: faster ball had greater energy of motion.").
- Fair-test language: *change one thing · keep important conditions the same · observe/measure the result.*
- Grade 4 terminology is used; kinetic/potential/compression-wave/radiant/inertia are **not** required student language.

## Friday (outside the 4-day rhythm)
- **Flex Science Friday** — RECOVER / PRACTICE / EXTEND only. Never introduce essential Monday-dependent content. See `FRIDAY_FLEX_FRAMEWORK.md`.

## Prep constraints
- Teacher prep period is **end of day** → favor reusable kits/bins, short setup, short reset, minimal consumables, minimal morning prep. Multi-day labs are acceptable.
