# WORKSHEET / ACTIVITY STANDARD

> Student lab/activity pages. Rules protect thinking, fair testing, and answer integrity.

## Rules
- do **not** force a one-page format
- Grade 4 writing space must be **generous**
- tables must be **readable**
- student pages must **not reveal expected results**
- teacher keys hold expected patterns/sample responses (see `TEACHER_KEY_STANDARD.md`)
- include **Prediction** where appropriate
- include **Fair Test** structure where appropriate (change one thing · keep others same)
- distinguish **observation** from **inference**
- use only measurements that actually answer the **Big Question**

## Preferred student lab routine
```
QUESTION → PREDICT → TEST → OBSERVE/MEASURE → EVIDENCE → EXPLAIN
```

## CER progression
CER (Claim, Evidence, Reasoning) must **progress in difficulty across the unit**, not be identical every time:
- early: sentence frames + word banks
- middle: scaffolded boxes (claim / evidence / reasoning)
- late: open-ended CER with student-chosen evidence

## Answer integrity
- No expected results, sample "correct" data, or answer keys inside student pages.
- Keys live in the teacher bundle only.
