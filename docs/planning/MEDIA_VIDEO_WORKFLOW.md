# MEDIA / VIDEO WORKFLOW

> Media plan for the unit. Sourcing happens in a **later phase**; this is the architecture only.

## Media categories
- **Hook clip** — open a lesson with a phenomenon
- **Custom explainer** — project-authored video (see structure below)
- **Lab preview** — show setup/procedure before the lab
- **Real-world application** — transfer/transformation in daily life
- **Extension** — enrichment beyond core
- **Absent-student recovery** — replay the investigation

## Custom explainer target
- **4–7 minutes**

### Structure
| Time | Section |
|---|---|
| 0:00–0:30 | hook (phenomenon) |
| 0:30–1:15 | Big Question |
| 1:15–4:30 | explanation |
| 4:30–5:30 | visual model (energy-flow chain) |
| 5:30–6:00 | challenge question |

## Possible future sources (NOT yet researched)
- BrainPOP / BrainPOP Jr. · National Geographic · PBS LearningMedia · Generation Genius · SciShow Kids · museums/science centers/universities · custom NotebookLM/Gemini

## Rules
- Every video must have an **instructional purpose** (hook, preview, explanation, application, extension, recovery).
- Custom media uses **Grade 4 terminology** (no kinetic/potential/compression-wave as required).
- No broad web research in this phase — sourcing is deferred.
