# CHAPTER PACKAGE STANDARD

> Every chapter ships the same three-bundle shape. This is a **target schema** for Phase 2+ production, not content built yet.

## Bundles per chapter

### TEACHER
- Chapter Teacher Map (objectives · sequence · Big Questions · TG lesson crosswalk)
- Daily sequence (Option A/B/C/D per day)
- Reader alignment (printed + PDF page ranges)
- Objectives (lesson-level)
- Vocabulary (new / revisited / supporting / not-yet-expected)
- Misconceptions (from `MISCONCEPTION_MAP.md`)
- Materials (from `MASTER_SUPPLY_MATRIX.md`)
- Prep (setup/reset/cleanup; end-of-day prep)
- Friday options (RECOVER / PRACTICE / EXTEND)
- Answer keys (separate from student pages)
- Absent-student plan (recovery pathway)

### STUDENT
- Guided notes (see `STUDENT_NOTES_STANDARD.md`)
- Practice
- Activity / lab pages (see `WORKSHEET_ACTIVITY_STANDARD.md`)
- CER / science writing
- Chapter review
- Chapter quiz (see `QUIZ_STANDARD.md`)

### MEDIA
- Classroom presentation (see `SLIDE_DECK_STANDARD.md`)
- Custom explainer script (see `MEDIA_VIDEO_WORKFLOW.md`)
- Curated external media (sourced in a later phase)
- Optional extension media

## Dual tagging (required on every resource)

### Priority tag
- **CORE** — required for the learning goal
- **FLEX** — optional; Friday-usable; never blocking
- **EXTENSION** — enrichment beyond core

### Provenance tag
- **SOURCE** — taken from authoritative CKSci
- **ADAPTED** — modified from authoritative/supplemental
- **CUSTOM** — authored for this project
- **EXTENSION** — new enrichment beyond source
