# FRIDAY FLEX FRAMEWORK

> Friday = **Flex Science Friday**. Never introduces essential new core content. Always optional/flexible.

## Three broad modes

### RECOVER
- missing lab · unfinished notes · absent recovery · corrections

### PRACTICE
- review game · puzzle · card sort · vocabulary-in-context · graph/data practice · error detective

### EXTEND
- mini STEM challenge · phenomenon · engineering challenge · media · deeper investigation

## Recurring Friday formats (rotation menu)
- **Energy Mystery Files** — infer the energy story from clues
- **Transfer / Transformation / Both** — sort real scenarios
- **Energy Chain Error Detective** — find the broken link in an energy chain
- **Collision Predictor** — predict then test a collision outcome
- **Escape Code** — short puzzle review
- **Odd One Out** — which item doesn't belong and why
- **Design Repair Shop** — improve a flawed device design on paper

## Rules
- nonessential to Monday continuation
- low-prep, reusable, quick reset (end-of-day prep)
- any Friday activity can be skipped without breaking the unit
