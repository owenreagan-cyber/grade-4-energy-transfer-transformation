# PRODUCTION FORMATS

> Editable-first production. PDF is a **release/export** format, never the only editable source.

## Source-format map
| Artifact | Editable source | Release/export |
|---|---|---|
| Presentations | PPTX / Google Slides | PDF (optional) |
| Notes / worksheets / quizzes / keys | DOCX / Google Docs / structured source | PDF |
| Planning / specs | Markdown | — |
| Structured data | CSV/JSON **only where it adds value** | — |

## Rules
- Do **not** make PDF the only editable source.
- **Never rename authoritative source assets** (the CKSci PDFs keep their original filenames).
- All project-generated files follow the naming convention below.

## Naming convention
```
NN-chN-shortname-<role>.<ext>
```
Examples:
```
01-ch1-energy-causes-change-teacher-map.md
01-ch1-energy-causes-change-slides.pptx
01-ch1-energy-causes-change-notes.docx
01-ch1-energy-causes-change-lab.pdf
01-ch1-energy-causes-change-quiz.docx
```
- `NN` = chapter index (01–09 where 09 = unit review/assessment).
- `shortname` = kebab-case, lower-case, no spaces.
- `<role>` = teacher-map, slides, notes, lab, quiz, key, review, etc.
- Authority assets (e.g., `Science 4 - Energy Transfer - Student Book.pdf`, `Chapter_1_Energy_Causes_Change.pdf`) are **excluded** from this convention — leave untouched.
