# TEACHER KEY STANDARD

> Every assessment, quiz, worksheet, and lab page has a separate teacher key.

## Key must include
- **expected answers**
- **acceptable alternatives** (right answers that differ in wording)
- **expected pattern** (what a correct response generally looks like)
- **common misconception** (what students will likely say wrong and how to respond)
- **scoring notes** (partial credit, point allocation)
- **troubleshooting** (what to do when the activity yields unexpected results)
- **what NOT to penalize** (e.g., spelling, informal phrasing, correct reasoning on a failed prototype)
- **source alignment** (which Reader/TG lesson or AP the item maps to)

## Hard rules
- Keys are **never** mixed into student PDFs.
- Keys cite source page numbers where applicable (e.g., "Reader p. 17; TG L7").
- For open items, provide a sample response **plus** the range of acceptable alternatives.
