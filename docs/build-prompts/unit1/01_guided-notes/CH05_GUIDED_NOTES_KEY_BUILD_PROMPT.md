# BUILD PROMPT — Chapter 5 Guided Notes (Teacher Key)

> Standalone production prompt. Companion to `CH05_GUIDED_NOTES_STUDENT_BUILD_PROMPT.md`.

## 1. Mission

Produce the teacher key for Chapter 5 Guided Notes — a page-for-page, blank-for-blank mirror of the student file with answers filled into the student geometry. **No mass/weight comparison is required content.**

## 2. Exact resource name

`05-ch5-collisions-transfer-energy-guided-notes-key` — **Chapter 5: Collisions Transfer Energy — Guided Notes Key (Teacher)**

## 3. Audience

Teacher only.

## 4. Required / optional status

**REQUIRED · CORE · teacher-only**.

## 5. Instructional purpose

Give the teacher exact expected fills, acceptable alternatives, and — concisely — one major misconception per section and the source page.

## 6. Source authority (order is authoritative)

1. **Authoritative Student Reader** (Ch5, pp. 25–30 / PDF 31–36). 2. **Authoritative Teacher Guide** (L10–11, pp. 65–77). 3. **Current accepted pacing** (`curriculum/chapter-05/source-map.md`). 4. **Current Guided Notes architecture**. 5. **Slides after re-sync**. 6. **Assessment blueprint** (Q4, Q12, Q23).

> **RULING:** the assessment blueprint is a **traceability check, not curriculum authority.** Do not distort the curriculum to satisfy it.

## 7. Required content — the answer set

Mirror the student anchors exactly (BQ · V1 · N1–N3 · fair-test · CHECK · BQ·NOW I THINK). Representative answers:

- **V1 — collide:** "to come together with impact." **V1 — collision:** "an instance of colliding." **V1 — sound:** "a form of energy that comes from a vibrating object."
- **N1 changes:** "motion can change · direction can change · an object can begin moving / stop / slow / change direction."
- **N2 before/after:** BEFORE "the moving object heads toward the target" / AFTER "the moving object slows or stops and the target moves." Evidence: "the target moved (that is the change)."
- **N3 outcomes:** "some energy transfers to motion" · "sound may occur" · "a tiny amount of heat may occur" · anchor: "energy does NOT disappear." (Do NOT require a heat measurement.)
- **Fair-test:** "same object(s), change speed only — change ONE thing, keep everything else the same."
- **CHECK / BQ·NOW I THINK:** "Sample answer — student wording may vary."

## 8. Explicit exclusions

Same locked boundaries: **no mass/weight comparison as required content** (Reader p.30 weight content is deferred to oral/demo enrichment; do not add it to the key as a required fill), no momentum/impulse/force/deformation required, no measured heat, no kinetic/potential/mechanical/radiant/inertia, no Ch6 engineering. No answer appears on any student page.

## 9. Page count target

Identical to the student file (target 2–3 pages, same order/geometry). The key must never drift to a different page count.

## 10–17. Layout, margins, typography, spacing, handwriting, tables, header, page-by-page

Inherit the student file layout **exactly** (US Letter portrait; margins 0.50–0.55 in; same typography/tables/diagrams/geometry; same page breaks; same line placement).

**Geometry parity rule (locked):** preserve the student page geometry exactly wherever possible — including **Name/Homeroom header geometry**, anchor positions, page breaks, margins, line placement. **Do NOT reflow the page.** Do NOT remove or simplify the Name/Homeroom line. Add a small, non-reflowing `TEACHER KEY` badge in a fixed corner/header position only.

## 18. Key architecture / answer treatment

Gold or dark blue, bold; no red by default. Small `ANSWER`/`SAMPLE` labels. Fill into student blank geometry. Open responses: `Sample answer — student wording may vary.` + acceptable alternatives.

**Commentary limit (locked):** concise per section — expected answer, acceptable variants, one major misconception if needed, source page if helpful. If commentary exceeds space without distorting student geometry, use (1) a small keyed margin note if room exists, (2) a compact footer keyed to anchor code, or (3) a separate one-page teacher appendix. **Never shrink student geometry or typography to fit teacher commentary.**

## 19. Answer / scoring rules

Not scored. List acceptable alternatives and what NOT to require. Misconception notes: "energy transfers, it does not disappear"; "we do not measure the collision's heat"; "mass/weight comparison is NOT required here (deferred)."
