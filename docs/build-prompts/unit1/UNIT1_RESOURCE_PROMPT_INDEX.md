## Status vocabulary (two independent axes)

**Content Status** (does the instructional content exist and is it current?)

| Status | Meaning |
|---|---|
| `CURRENT` | Canonical, on-architecture, in the active release path. |
| `STALE` | Exists but off-architecture (pre-reconciliation, INB-era, or missing a key). |
| `MISSING` | Does not exist at all. |
| `HISTORICAL` | Superseded; preserved for provenance, never assigned. |
| `RETIRED` | Retired architecture (Interactive Science Notebook); excluded from release. |

**Printable PDF Status** (does an actual printable PDF exist in the active release — **not** merely Markdown/source?)

| Status | Meaning |
|---|---|
| `PDF_CURRENT` | A printable PDF exists and is current. |
| `PDF_NEEDS_POLISH` | PDF exists but needs a header/badge/non-content pass. |
| `PDF_NEEDS_REBUILD` | PDF exists but is off-architecture; rebuild required. |
| `PDF_MISSING` | No printable PDF exists (Markdown/content-only, or not built). |
| `NOT_APPLICABLE` | Not a printable surface (internal spec, map, plan, media script). |

**Source/Edit Status** (`DOCX` editable master · `MD` Markdown-only · `PPTX` deck · `PDF` export-only) and **Recommendation** (`KEEP` · `POLISH` · `REBUILD` · `CREATE` · `ARCHIVE` · `RETIRE`).

> **Rule:** a resource is NOT "classroom-ready" merely because Markdown/source exists. Printable-PDF status is a separate judgment.
