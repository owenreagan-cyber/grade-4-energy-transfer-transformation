## Variable-isolation guardrail (the core Chapter 5 boundary)
- **Speed vs mass confound:** Part A changes ONLY ramp height (same car/target/surface); Part B changes ONLY mass (same ramp/target/surface). Never both at once. Addressed in the Crash Lab worksheet, lab spec, teacher notes, slides 13/16/20, and the answer-key "variable-isolation check" section. ✅
- **Measured vs inferred:** students measure target displacement (cm) and INFER relative speed/energy. Never "measured speed/energy." ✅

## Sound and heat boundary
- Sound = qualitative only (loud/quiet); no decibels. ✅
- Heat = not measured; "a tiny bit of heat" is optional source-aligned language only. ✅
