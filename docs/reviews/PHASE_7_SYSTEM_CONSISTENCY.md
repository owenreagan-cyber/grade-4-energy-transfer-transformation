## Standards changed (deliberate)
1. **Two-part variable isolation** — official AP 11.2 "change one variable" is split into Part A (speed: same car, vary ramp height) and Part B (mass/weight: same ramp, vary mass), each with fixed-set comparisons. This enforces the locked Phase 7 guardrail that speed and mass are NEVER confounded. Recorded in source map + teacher notes + source-validation + answer keys.
2. **Target-displacement measurement** — official answer key measures target distance "by car lengths"; Phase 7 uses cm displacement with 3 trials + averaging (consistent with Phase 5's measured-outcome approach). Depth and loudness are NOT primary data (Phase 6 decision). Recorded in source map.
3. **Sound qualitative / heat not measured** — formalized from TG L10 "Know the Standards 2" (sound is heard; heat is "a very small amount ... difficult to measure"). Recorded in teacher notes + data quality.
