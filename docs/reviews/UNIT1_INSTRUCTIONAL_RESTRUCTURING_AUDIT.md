## Reconciled Decisions

> Authoritative resolutions incorporated into this revision. Where these conflict with the first audit, the decision below governs.

### RD-1 — Pom-Pom Launcher is REQUIRED (not optional)
The Pom-Pom Launcher is a **REQUIRED common hands-on synthesis/build** for Unit 1. Classification: **REQUIRED ACTIVITY / BUILD** — *not* a formal quantitative lab, *not* a major graded assessment. It reinforces stored energy, energy of motion, transfer, transformation, fair testing, and improvement, with a **formative follow-up** (not a major grade). It is **not** demoted to optional/FLEX. It is a net-new artifact (borrowed/adapted from colleague materials) and must be built with a latex-safety / latex-free note.

### RD-2 — Chapter 4 has NO required student lab
Intentional. Target Ch4 = Balloon Drum/salt sound-transfer **DEMO** + virtual backup + vocabulary + Reader + embedded checks + mirrored notes + **source → path → receiver → evidence organizer/application** + custom practice if needed + Big Question return. **No circuit kit, no hot plate, no transfer stations, no required quantitative student lab.** A per-item assessment coverage trace is provided in §N, concluding **no assessment-preparation hole** remains (none of Q13/Q17/Q20/Q25 require student-generated quantitative data).

### RD-3 — Chapter 5 gets NO second ramp lab (locked)
Target Ch5 = Toy-Car Collision **DEMO** + virtual backup + vocabulary + Reader + embedded checks + mirrored notes + before/after collision diagram + collision scenarios + custom application/practice + Big Question return. The Crash/Collision lab is **reclassified out of required core**. Audit confirms no Ch5 assessment item requires students to collect their own collision measurements (§N). Ramp It Up already provides the flagship quantitative ramp/speed/change investigation.

### RD-4 — Engineering is SPLIT into two levels
- **BEFORE assessment (Ch6–7):** students MUST still learn and practice engineering design, criteria, constraints, design, test, evaluate, improve/refine, and applying transfer/transformation to useful devices. This compact engineering **content stays in-unit** and supports Q15 and Q22.
- **AFTER assessment:** the **large open-ended STEM Design Challenge** occurs as post-test enrichment.
Re-traced under this distinction in §N (Q15, Q22).

### RD-5 — Ramp It Up re-audited against the newest spec → ADAPT
The current Ramp It Up 2.0 is **not** a clean KEEP. A requirement-by-requirement comparison (§J) shows several material items MISSING (calibration trial, explicit group roles, recording actual ramp height in cm, the 30-cm Design-Your-Ramp challenge, dimensioned standard track). Classification: **ADAPT** (not KEEP, not REBUILD). Not edited in this phase.

### RD-6 — Ch1/Ch2 note-cue density → KEEP, with evidence
Do **not** add notes for symmetry. Analysis (§F) concludes Ch1 and Ch2 note density is appropriately concise, all durable concepts and assessment concepts are present, and adding cues would increase copying rather than retention. **KEEP CURRENT NOTE DENSITY.**

### RD-7 — Ch5 slide-spec gap is structural
Ch5 has a slideshow outline but no `.md` slide spec (unlike Ch1–4, Ch6–7). Root cause and remediation are documented in §G. Bringing Ch5 under the same spec architecture is a **future implementation-phase item**, not a pilot prerequisite. The spec is **not** created now.
