# STUDENT HANDOUT STANDARD

> Worksheets, lab/activity pages, and other student handouts. Populated from established decisions only.
> Sources: `docs/planning/WORKSHEET_ACTIVITY_STANDARD.md`, `docs/planning/TEACHER_KEY_STANDARD.md`, `docs/reviews/UNIT1_INSTRUCTIONAL_RESTRUCTURING_AUDIT.md` (§J, §K).

## Rules
- Do **not** force a one-page format.
- Grade 4 writing space must be **generous**: ruled answer lines; ≥2 lines for explain prompts.
- Tables must be readable; min row height 0.5" (portrait) / 1.1" (landscape investigation tables); shaded header row.
- Student pages must **not reveal expected results**.
- Include **Prediction** where appropriate.
- Include **Fair Test** structure where appropriate (change one thing · keep others same).
- Distinguish **observation** from **inference**.
- Use only measurements that answer the **Big Question**.

## Preferred routine
```
QUESTION → PREDICT → TEST → OBSERVE/MEASURE → EVIDENCE → EXPLAIN
```

## CER progression
- Early: sentence frames + word banks.
- Middle: scaffolded boxes (claim / evidence / reasoning).
- Late: open-ended CER with student-chosen evidence.

## Experiential taxonomy (reconciled §J)
- `DEMO` · `ACTIVITY` · `LAB / INVESTIGATION` · `REQUIRED BUILD` · `OPTIONAL / FLEX` · `POST-TEST STEM`.

## Answer integrity
- No expected results, sample "correct" data, or answer keys inside student pages.
- Keys live in the teacher bundle only (see `TEACHER_KEY_STANDARD.md`).

## Teacher keys (see `docs/planning/TEACHER_KEY_STANDARD.md`)
- Expected answers · acceptable alternatives · expected pattern · common misconception · scoring notes · troubleshooting · what NOT to penalize · source alignment.
