# SLIDESHOW LOGIC LOCKDOWN

> Locked rules governing slide ↔ notes ↔ Reader synchronization. Populated from established decisions only.
> Sources: `docs/reviews/UNIT1_INSTRUCTIONAL_RESTRUCTURING_AUDIT.md` (§C, §G, §H), `docs/reviews/UNIT1_CH1_PILOT_PREBUILD_AUDIT.md` (§H), `docs/planning/ENERGY_GUIDED_NOTES_SLIDE_ALIGNMENT.md`.

## Notes-first rule
- Guided Notes are designed **before** the corresponding slideshow.

## Exact mirror rule (BQ/V/N)
- Every **NOTES-mode slide** matches the paper exactly: same section label, wording, bullets, blanks, order, and diagram.
- BQ/V/N anchors on slides mirror student notes exactly.

## Scope of the mirror rule
- The mirror rule applies to **NOTES-mode slides only**; it does **not** require every notes blank to have a cue slide.
- Hooks and review MCQ slides are explicitly `DEMO` / `DISCUSSION`, not hidden curriculum.
- No hidden required note answers may appear on unrelated slides.

## Reveal discipline
- Fill-in answers are **revealed, not front-loaded** (prediction-before-reveal).

## Vocabulary discipline
- **TEACH** (full-screen card, exact source def + Reader page) vs **RECORD** (fill-in from memory, card covered).
- Card appears **after** the hook phenomenon and **before** the read-aloud (observe-first).

## Canonical sequence rule
- One chapter = **one canonical slide sequence**; the deck is authoritative.
- Regenerate the spec to match the deck; retire outline/spec drift (e.g., Ch1 deck = 26 slides canonical; outline 28 / spec 25 were reconciled).

## Chapter choreography (9-step grammar)
`BIG QUESTION → PHENOMENON → VOCAB CARDS → VOCAB NOTES → READ → CHECKS → CONCEPT NOTES → APPLICATION → RETURN TO BQ`
