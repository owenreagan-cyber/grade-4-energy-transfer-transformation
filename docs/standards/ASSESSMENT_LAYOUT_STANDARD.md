# ASSESSMENT LAYOUT STANDARD

> Quizzes, final assessment, study guides, and keys. Populated from established decisions only.
> Sources: `docs/assessment/UNIT1_FINAL_ASSESSMENT_BLUEPRINT.md` (locked), `docs/planning/QUIZ_STANDARD.md`, `docs/planning/CURRENT_DECISIONS.md` (Phase 3 quiz balance), `docs/reviews/UNIT1_INSTRUCTIONAL_RESTRUCTURING_AUDIT.md` (§M, §N).

## Chapter quizzes
- Target: **8–12 items / 10–15 minutes**.
- Balance: ~50% current concept · ~25% application/data · ~25% evidence (no forced prior-unit spiral).
- Assess vocabulary **in context**, not isolated matching.
- Avoid trick wording, advanced terminology, mass+speed confounds (use the **same object** for speed–energy items).
- Answer key is separate.

## Unit final assessment (locked)
- **25 questions · 50 points · 2 points each · MATCHING + MULTIPLE CHOICE only.**
- Q1–8 matching (8 terms, 11 definitions, 3 extras) · Q9–25 multiple choice (4 options each).
- **Source rule:** Notes define the testable boundary; the Reader verifies the science.
- Font: Calibri; titles bold; student-facing floor 12 pt (questions 13.5 pt); 3–4 student pages.
- Difficulty labels: LITERAL · COMPREHENSION · VISUAL · COMPARISON · APPLICATION · INFERENCE.
- Target ≈3–5 harder (inference) items; balanced answer-key distribution.

## Scoring
- **All scored work = raw score + percentage.**
- Keys cite source page numbers (e.g., "Reader p. 17; TG L7").

## Study guide / review
- Study guide + clickable review game aligned to the 25Q final.
- Slight over-coverage in the study guide is acceptable (not a flaw).
