# EXTERNAL VIDEO SOURCING STANDARD (Unit 1 + Unit 2)

> Governs how Grade 4 Science Units 1 & 2 select, evaluate, register, and embed **external** educational video (YouTube + trusted science-education organizations) alongside **project-authored** media. Applies equally to both.
> Companion to: `DIAGRAM_AND_MEDIA_STANDARD.md`, `docs/planning/MEDIA_VIDEO_WORKFLOW.md`, `TWO_UNIT_MEDIA_MAP.md`, `WHOLE_UNIT_MEDIA_STAGING.md`.
> Authoritative curriculum = CKSci Student Reader + Teacher Guide. Never overridden by any video.

## 0. Non-negotiables (inherited, always apply)

- No `kinetic`, `potential`, `gravitational potential`, `mechanical`, `radiant`, `compression wave`, `inertia` as required vocabulary — **including in any external video's narration/captions**.
- No transfer-vs-transformation classification, speed–energy comparison, or mass/velocity language in Chapters 1–2 (those are Ch.3–6 scope).
- Use **"evidence"**, never "proof/proves/prove".
- Transfer (moves) vs transformation (changes form) — allow BOTH; never conflate.
- A video never overrides the Reader/TG. It is a support artifact only.

## 1. Flexible duration standard (Grade 4, Units 1–2)

| Tier | Range | Use |
|---|---|---|
| Quick observation / demo | **15–60 s** | Single phenomenon, BEFORE/AFTER, bell-ringer retrieval |
| Focused explanation | **1–2 min** | One concept, one model step |
| Deeper explanation / process | **3–5 min** | Longer concept, engineering process, multi-example |
| Extended | **> 5 min** | Allowed **only** when justified by curriculum importance and pacing; never stacked |

- **Do not auto-trim an effective 3–5-minute video merely to meet an artificial limit.** Trim only when the edit removes off-scope or over-advanced content (vocabulary, later-chapter scope, speculation).
- Record exact `start`–`end` timestamps for any excerpt; the full source is retained but the approved excerpt is what is placed.
- 0–1 CORE video per lesson; longer videos are strategically placed, never stacked.

## 2. Discovery & evaluation pipeline

For each lesson and required concept:
1. Review currently **approved** project videos first (reuse before replacing).
2. Identify the instructional gap (hook / explain / lab preview / application / extension / recovery).
3. Search reputable external sources + YouTube (web search; YouTube Data API when a key is available).
4. Evaluate each candidate against the Reader + Teacher Guide (same concept, same wording, correct apparatus).
5. Prefer short, visually clear clips with directly observable phenomena.
6. Check narration, captions, age suitability, pacing, and later-chapter vocabulary.
7. Record exact start/end timestamps for longer videos.
8. **REJECT/RESTRICT** distracting, inaccurate, speculative, or over-advanced content.

Reject on: forbidden vocabulary · wrong concept · later-chapter scope creep · safety issue · unplayable · inappropriate content. A minor wording issue the teacher can contextualize is a **NOTE**, not a rejection.

## 3. Media registry — required fields

Each external candidate is recorded with, at minimum:

| Field | Meaning |
|---|---|
| Publisher | Organization / channel |
| Original URL | Canonical source link |
| Video ID | YouTube ID or platform ID |
| Title | Display title |
| Duration | Full + approved excerpt |
| Date checked | Last verification date |
| Curriculum concept + chapter | Concept ID + chapter |
| Approved excerpt timestamps | `start`–`end` |
| Transcript/caption verification | verified / not verified |
| Scientific accuracy | Reader/TG alignment result |
| Rights & embedding | embeddable / link-only / login / subscription |
| Student-safety considerations | age fit, ads, autoplay-next |
| Placement in lesson | lesson + day + before/after |
| Google Slides ID + slide position | deck id + slide number |
| Fallback option | live demo / still / oral re-teach |
| Approval status | see §4 |

## 4. Approval status vocabulary

Exactly one of: `DISCOVERED` · `CANDIDATE` · `REVIEWED` · `APPROVED` · `REJECTED` · `IMPLEMENTED`.

- `DISCOVERED` — located; unevaluated.
- `CANDIDATE` — evaluated; provisionally suitable; awaiting full verification.
- `REVIEWED` — full transcript/caption + accuracy check done; awaiting owner approval.
- `APPROVED` — owner-approved for use.
- `REJECTED` — fails a non-negotiable.
- `IMPLEMENTED` — embedded in the teaching deck.

Status changes require source evidence; never invent approval. Classifications cite the review or manifest that supports them.

## 5. Google Slides media-slide template

Native Google Slides is the primary classroom teaching format. Each selected video gets its **own dedicated media slide** containing:
1. **Brief introduction** (1–2 lines setting context).
2. **Find Out / Follow Along question** (one observable-focus question read before playback).
3. **Embedded video or reliable approved playback link**.
4. **Correct aspect ratio + readable layout** (16:9 preferred; poster frame; no autoplay — teacher-clicked).
5. **Teacher-facing follow-up / discussion note** (speaker notes).

- Preserve original instructional slides and their order; insert media slides adjacent to the concept they support.
- Do **not** replace approved existing videos merely because a newer external option exists.

## 6. Operational requirements

- Keep total video viewing within the 30-minute period, accounting for recess return, Reader handling, discussion, cleanup, and departure.
- Never make external internet playback the **only** way to teach a required concept.
- Provide a still-image or live-demo fallback for every video slot.
- Independently verify actual playback within Google Slides, including on the iPad Pro when practical (isolated/Simulator or owner-approved bounded live test).
- Recheck links and embeddability before classroom use.

## 7. Copyright

Do not download or redistribute copyrighted videos without appropriate permission. Prefer native embed or link-to-source; the repository stores only project-authored media and metadata manifests (hash/URL/status), never pirated copies.
