# SLIDESHOW STANDARD

> Classroom presentation standard. Populated from established decisions only.
> Sources: `docs/planning/SLIDE_DECK_STANDARD.md`, `docs/reviews/UNIT1_CH1_PILOT_PREBUILD_AUDIT.md` (§L), `docs/reviews/UNIT1_INSTRUCTIONAL_RESTRUCTURING_AUDIT.md` (§C, §G).

## Rules
- **One core instructional idea per slide.**
- Large, classroom-readable type; minimal paragraphs (no walls of text).
- Strong visuals, diagrams/arrows/models.
- **Prediction prompts** (pause before reveal) and **reveal sequences** (don't show the answer with the question).
- Student discussion prompts; ready-to-project directions.
- Timers only when useful; avoid decorative clutter.

## Two kinds of decks (separate)
- **Teaching slides** — concepts, discussion, reading support.
- **Lab/activity slides** — directions, safety, data tables, timers.

## Mode badges (established §L)
- `BQ` (Big Question) · `D` (demo) · `V` (vocab) · `R` (read) · `C` (check) · `N` (notes) · `W` (write) · `T` (talk) · `P` (practice) · `J` (journal).
- Badges signal mode-shift, not re-theme.

## Type hierarchy (established tokens)
- Deck major 50 pt · slide title 42 pt · body 32 pt · labels 28 pt (labels ≥28 pt for projector readability).

## Slide types
- **Vocab card:** large word + icon/illustration + exact source definition + Reader page + "TEACH" tag.
- **Notes slide:** exact mirror of paper + "NOTES" mode badge.
- **Reading slide:** Reader page number + section heading + permitted crop.
- **Check slide:** A/B/C/D or signal (thumbs), one check per idea.
- **Demo slide:** BEFORE/AFTER + "predict first — then watch".

## QA checklist (every deck)
- One idea per slide · readable projection size · no crowded paragraphs · visual clarity · no off-screen/cutoff content.
