# VISUAL DESIGN SYSTEM

> Unit-wide visual identity. Populated from established decisions only (no new art direction).
> Sources: `docs/reviews/UNIT1_CH1_PILOT_PREBUILD_AUDIT.md` (§L, §F), `docs/reviews/UNIT1_INSTRUCTIONAL_RESTRUCTURING_AUDIT.md` (§P), and **Phase 1 Visual Design System** (`docs/reviews/PHASE_1_VISUAL_DESIGN_SYSTEM_REVIEW.md`).

## Goal
- **Family resemblance + clear mode shifts**, not one identical template.
- **Premium visual quality** required; every visual teaches — no decorative clutter.
- Target: **modern museum exhibit + excellent elementary science textbook + strong teacher presentation**.

## Authoritative sources (final, accepted)
- **Machine-readable tokens:** `assets/visual-system/design-tokens.json` (single source of truth; `design_system_version = 1.0`, status `FROZEN`).
- **Figma parity snapshot:** `assets/visual-system/figma-parity-manifest.json` (QA snapshot of Figma values, validated by `tools/qa_visual_system.py`; **not** a source of truth).
- **Human references:** `docs/visual-system/UNIT1_DESIGN_TOKENS.md` · `docs/visual-system/COMPONENT_CATALOG.md` · `docs/visual-system/CHAPTER_THEME_MAP.md`.
- **Reusable assets:** `assets/visual-system/{icons,hud,badges,vocabulary,diagrams,chapter-themes}/` (SVG, generated by `tools/build_visual_system.py`).
- **Figma source (pilot):** `Grade 4 Energy — Unit 1 Visual System` (design source, not a production dependency).

## Design-system version & freeze (final)
- **Version identifier:** `UNIT1_VISUAL_SYSTEM_VERSION = 1.0` — stored in `design-tokens.json` (`design_system_version`) and **nowhere else** (no competing version source).
- **Single source of truth:** `design-tokens.json` is canonical. Figma **mirrors** these tokens; exported SVGs **mirror** these tokens; DOCX/PPTX generators must **consume or reproduce** these values.
- **Change policy:** any future visual-system change requires (1) a token update in `design-tokens.json`, (2) regenerated assets (`tools/build_visual_system.py`), and (3) a QA re-run (`tools/qa_visual_system.py`, all gates PASS) before the change is accepted.
- **Known substitution:** canonical font is Avenir Next (system font for local SVG/PDF); the Figma pilot substitutes Inter because Figma does not bundle Avenir Next. Non-blocking; local canonical assets stay Avenir Next.

## Palette (final)
- **Unit neutrals:** ink `#1A1D26` · ink_soft `#4A5268` · paper `#FFFFFF` · mist `#F6F7F9` · rule `#D8DCE4`.
- **Chapter themes:** seven locked themes with exact hex values — see `docs/visual-system/CHAPTER_THEME_MAP.md`.
- Grayscale-safe (all primaries/accents ≥ 3:1 vs white after desaturation; primary darker than accent).

## Type hierarchy (final)
- **Slide:** deck major 50 pt · title 42 pt · body 32 pt · label 28 pt (projector floor 28 pt).
- **Handout:** title 26 pt · section 16 pt · body 14 pt · caption/page-ref 11 pt (body floor 12 pt).
- Primary family **Avenir Next** (fallback Helvetica Neue → Helvetica → Arial).

## Badges (final)
- **Chapter badge / tab:** `CHAPTER N · <TITLE>` top-left, in chapter `primary`.
- **Resource badges:** `GUIDED NOTES · PRACTICE · LAB · SCIENCE JOURNAL · REVIEW · STEM CHALLENGE` (single `ink` pill; document-level, not repeated per page).
- **HUD action bubbles:** `RECITE · WRITE · PREDICT · VOTE · TURN & TALK · CHECK · TRACE · DRAW · WATCH` (+ optional `OBSERVE · EVIDENCE · DATA · ENGINEER · EXPLAIN`). Temporary action guidance — **not** note navigation (`BQ / V1 / V2 / N1 / N2` remains permanent).

## Diagram style (final)
- Arrows = "model, not mechanism" (no compression-wave/electron detail).
- Transfer = straight · Motion = curved · Transformation = diamond marker · Cause/effect = chevron.
- Two-panel BEFORE/AFTER for comparisons, consistent labels.

## Component system (final)
- Full reusable-component specs: `docs/visual-system/COMPONENT_CATALOG.md` (Unit title, Chapter title, BQ panel, notes BQ anchor, vocabulary card, V/N section treatments, HUD bubble, resource badge, diagram label, before/after panel, data table, student graph, teacher callout, assessment header, score box, lab setup diagram, playbook chapter tab).

## Photo treatment
- Only where realism matters; clean frame; no stock clutter.

| Worksheets | STANDARDIZED HEADER / BADGE |
| Lab packets | STANDARDIZED HEADER / BADGE |
| Quizzes / Assessment | NO CHANGE |
| Study guide | LIGHT CLEANUP (badge) |
| Infographics / Review game | NO CHANGE (already premium) |

## Accessibility / contrast (final)
- WCAG AA: body ≥ 4.5:1 · large text (≥ 24 pt) ≥ 3:1 · accent graphics ≥ 3:1 · projector target ≥ 4.5:1.
- Grayscale: color never the only signal; label text + shape + position carry meaning.

## Validation (final)
- **Automated QA:** `tools/qa_visual_system.py` runs nine headless gates — contrast, grayscale survival, font floors, overflow/margins, SVG render integrity, component consistency, token validation (freeze version + dims), Figma parity (manifest vs tokens vs local assets), and grayscale-proof integrity. All must report PASS before the system is treated as frozen.
- **Grayscale proof:** `tools/build_visual_system.py` emits `qa/temp/phase1_visual/grayscale_proof.png` — a B/W contact sheet of the sample notes/assessment/slide, vocabulary card, and all 7 chapter palettes — for automated + human B/W legibility inspection.
