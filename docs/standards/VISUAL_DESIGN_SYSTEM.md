# VISUAL DESIGN SYSTEM

> Unit-wide visual identity. Populated from established decisions only (no new art direction).
> Sources: `docs/reviews/UNIT1_CH1_PILOT_PREBUILD_AUDIT.md` (§L, §F), `docs/reviews/UNIT1_INSTRUCTIONAL_RESTRUCTURING_AUDIT.md` (§P).

## Goal
- **Family resemblance + clear mode shifts**, not one identical template.
- **Premium visual quality** required; every visual teaches — no decorative clutter.

## Palette (established tokens)
- Navy `#2F3C7E` · Coral `#C03D3D` · Gold `#E8C54A` · Light `#F4F4F8`.
- Grayscale-safe (must survive B/W printing).

## Type hierarchy (established tokens)
- Deck major 50 pt · slide title 42 pt · body 32 pt · labels 28 pt.

## Badges (established)
- **Chapter badge:** `CHAPTER N · <TITLE>` top-left.
- **Mode badge:** pill — `BQ / D / V / R / C / N / W / T / P / J`.
- **Worksheet/activity header:** shared `UNIT 1 · CHn · PRACTICE/ACTIVITY` badge.

## Diagram style
- Arrows = "model, not mechanism" (no compression-wave/electron detail).
- Two-panel BEFORE/AFTER for comparisons, consistent labels.

## Photo treatment
- Only where realism matters; clean frame; no stock clutter.

## Family-level treatment (reconciled §P)
| Family | Need |
|---|---|
| Guided notes | LIGHT CLEANUP (badge + chapter number + page refs) |
| Worksheets | STANDARDIZED HEADER / BADGE |
| Lab packets | STANDARDIZED HEADER / BADGE |
| Quizzes / Assessment | NO CHANGE |
| Study guide | LIGHT CLEANUP (badge) |
| Infographics / Review game | NO CHANGE (already premium) |

## Flag
- Subjective visual review is required; do not auto-apply without inspection.
