# Guided Lab Reasoning Standard (Grade 4)

Required Grade 4 investigations must be structured so students reason from their
own data, not from a prewritten conclusion. Open-ended conclusions are not asked
before the data are read and compared.

## Architecture

Every required investigation walks through, in order:

1. **QUESTION** — one answerable question naming the variable and the observed change.
2. **PREDICT** — one prediction; the variable is named.
3. **COLLECT DATA** — a real data table with visible bordered cells.
4. **ORGANIZE / AVERAGE** — an average column where the design requires it.
5. **READ THE DATA** — a named cell/row/column question.
6. **COMPARE** — compare two named values.
7. **NOTICE THE PATTERN** — describe the direction of the pattern.
8. **CLAIM** — a sentence-completion claim tied to the pattern.
9. **CHOOSE EVIDENCE** — cite two actual values from the student's own table.
10. **EXPLAIN THE EVIDENCE** — say how those values support the claim.
11. **EXTEND YOUR THINKING** — exactly one transfer question.

Not every lab needs identical wording, but every required lab provides enough
structure for a Grade 4 student to reason from actual data.

## Rules

- **No open conclusion before guided reasoning.** Steps 5–8 come before any
  "why" or "what does this mean".
- **Evidence must be the student's own.** A key may use placeholders/sample data
  only when clearly labeled as a teacher example, never fabricated class data.
- **Fair-test controls are explicit.** Same object, same release, same measuring
  method, one changed variable.
- **Units are stated.** "cm", "books", or "trials" are named where they apply.
- **No fake measurements.** A lab never invents a speed or energy value the
  student did not measure.

## Source-faithful reasoning for speed vs energy

- **Source knowledge:** a steeper ramp means the same object picks up more speed
  (Reader p. 15, TG Lesson 5 "Know the Science").
- **Investigation observation:** a faster-moving same object causes a greater
  observable change (e.g., the cup moves farther).
- **Conclusion:** greater speed of the same object is associated with greater
  energy of motion.

Cup movement is evidence of the greater **change**, not a speed measurement.
Height is not called speed.
