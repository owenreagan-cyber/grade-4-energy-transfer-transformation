# DIAGRAM & MEDIA STANDARD

> Visuals and media. Populated from established decisions only.
> Sources: `docs/reviews/UNIT1_CH1_PILOT_PREBUILD_AUDIT.md` (§E, §F, §I), `docs/reviews/UNIT1_INSTRUCTIONAL_RESTRUCTURING_AUDIT.md` (§I), `docs/planning/MEDIA_VIDEO_WORKFLOW.md`.

## Asset reuse classification
- `EXTRACT / REUSE` — already-correct visual, reuse as-is.
- `REFERENCE / RECREATE` — recreate cleanly (diagram, not photo) from the source idea.
- `DO NOT USE` — unstaged/unaccepted media or content outside the boundary.

## Diagram treatment (concept → treatment)
- Abstract concept → **labeled diagram** (definition card + arrow), not a photo.
- Comparison → **BEFORE/AFTER** two-panel.
- Simple cause→effect → **custom illustration** (no stock clutter).
- Reader photo with multi-change scene → **recreate as clean labeled diagram**.

## Media policy (strict)
- Correct apparatus; realistic physics; meaningful audio only when scientifically relevant.
- No advanced terminology (mechanical energy, radiant, compression wave, etc.).
- No glowing-energy / energy-as-visible-light misrepresentation.
- Unstaged supplemental media is **never** a build dependency.

## Virtual demo (optional, P3)
- Photorealistic clip; correct apparatus (e.g., electric sharpener, not hand).
- Primary evidence must be the intended change (e.g., pencil dull→sharp + sound), not incidental effects.
- One Ch1 clip as proof-of-concept only; do not scope-creep to all 7.

## Provenance
- Record media provenance in `SOURCE_INVENTORY.md` / `SOURCE_PROVENANCE.md`; excluded binaries tracked via inventory Markdown (no LFS, no MP4 embedded in PPTX).
