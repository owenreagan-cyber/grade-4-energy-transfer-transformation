# Final Assessment-Preparation Alignment

> Certifies that each unit's study guide and clickable review game review the
> concepts tested on the final assessment — without reproducing the test
> verbatim (no answer-order patterns, no distinctive distractors, no identical
> visual layout).

**Legend**

- **COVERED** — concept is directly reviewed by the study guide and/or game.
- **INTENTIONALLY NOT DUPLICATED** — concept is reviewed, but exact test wording
  is deliberately not repeated (anti-leakage).
- Status is never `MISSING`, `UNKNOWN`, or `TBD` for any tested concept.

## Anti-Leakage Notes

- Study guides review **concepts**, not test items. No exact assessment wording,
  no answer-order patterns, no distinctive distractors, no matching visual layout.
- Visual questions in the review game label neutral components or use a mystery
  `?` box — never the object being identified.
- `geothermal energy` is an approved term; it is used normally and correctly
  passes the `thermal energy` scope scan.
