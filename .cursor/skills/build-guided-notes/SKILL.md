# build-guided-notes

## When it applies
Building or editing guided notes for a Unit 1 chapter.

## Required inputs
- Authoritative Reader chapter (page range) + Teacher Guide lesson.
- `docs/standards/GUIDED_NOTES_STANDARD.md` + `docs/standards/UNIT1_PRODUCT_STANDARD.md`.
- Prior chapter notes (for cumulative retrieval + scaffold consistency).
- Vocabulary from `docs/planning/VOCABULARY_PROGRESSION.md`.

## Workflow
1. Inspect the Reader chapter + TG lesson directly.
2. Draft notes-first (before any slideshow).
3. Apply scaffold labels, page structure, per-section Reader page refs.
4. Add one model/diagram minimum per page; generous writing space.
5. Label provenance + priority.

## Outputs
- Editable DOCX master (release PDF via render only).

## Stop / failure conditions
- Any required advanced terminology (kinetic/potential/mechanical/radiant/compression-wave/inertia).
- Answer leakage on a student page.
- Density added "for symmetry" (RD-6 violation).
- Notes copy the Reader verbatim.

## Must obey
`GUIDED_NOTES_STANDARD.md`, `UNIT1_PRODUCT_STANDARD.md`, `VISUAL_DESIGN_SYSTEM.md`.
