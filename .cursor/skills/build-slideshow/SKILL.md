# build-slideshow

## When it applies
Building or editing a chapter slideshow.

## Required inputs
- Finished guided notes (notes-first).
- Canonical slide sequence/spec (deck is authoritative).
- `docs/standards/SLIDESHOW_STANDARD.md` + `docs/standards/SLIDESHOW_LOGIC_LOCKDOWN.md`.

## Workflow
1. Confirm guided notes are finalized.
2. Build to the 9-step choreography (BQ → phenomenon → vocab cards → vocab notes → read → checks → concept notes → application → return to BQ).
3. Apply mode badges, type hierarchy, palette, and mirror rule.
4. Keep one idea per slide; reveal sequences; no decorative clutter.
5. Regenerate the slide spec to match the deck (retire outline/spec drift).

## Outputs
- Editable PPTX master (+ matching `.md` slide spec).

## Stop / failure conditions
- BQ/V/N anchors diverge from the notes.
- Hidden required note answers on unrelated slides.
- Slide spec disagrees with the actual deck.
- Dense paragraphs or off-screen/cutoff content.

## Must obey
`SLIDESHOW_STANDARD.md`, `SLIDESHOW_LOGIC_LOCKDOWN.md`, `VISUAL_DESIGN_SYSTEM.md`.
