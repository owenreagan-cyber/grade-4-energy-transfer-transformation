# 6. NEW VISUAL GENERATION POLICY

**Do not rely on any previously generated Chapter 1 artwork.**

For this build:

1. Generate a fresh visual set from the briefs below.
2. Use the generated visual if it is scientifically accurate, visually strong, age-appropriate, and compositionally useful.
3. If a generated visual is materially inferior, ambiguous, unsafe, or scientifically misleading, fall back to a deterministic diagram or existing approved asset only after the generated version is rejected.
4. Never generate text inside artwork when the text can be rendered deterministically in PPTX.
5. Do not generate visible “energy” as glowing substance, aura, beam, magic light, particles, or force field.
6. Matched before/after scenes must keep camera position, objects, scale, lighting direction, and scene geometry stable unless the change itself requires otherwise.
7. Real-world phenomena should look photographic / physically plausible.
8. Concept models should be built with PPTX shapes, not baked into an image.

## Generation style

Use:
- premium elementary science textbook
- modern museum exhibit
- realistic classroom / household photography
- clean visual hierarchy
- believable materials and lighting
- no cartoon mascots
- no sci-fi
- no game UI
- no stock-photo watermark look
- no decorative clutter
